텐버거 찾는 꿀 Tip — 어닝콜 리서치 방법

한 줄 요약

어닝콜 시즌에 놓친 기업들을 주말에 몰아서 리서치하는 방법 — 구글에서 "기업명 + earning call + transcript" 검색으로 실제 CEO/CFO 발언과 기관 투자자 질문을 직접 확인하는 워크플로우.

원문

마지막, 텐버거 찾는 꿀 Tip.

요새 어닝콜 많으니깐, 일일히 챙겨보기 힘드시죠.

저는 보통 주말에 몰아서 하나씩 제가 놓친 기업들 찾아보는데요.

물론 chatgpt나 클로드, 제미나이로 찾아서 돌려볼 수 있는데 실제 CEO나 CFO, 그리고 뱅오아나 Jane Street, Citadel 등등 기관 투자자들은 어떤 질문을 이 회사에 하는지도 중요하고, CEO가 무슨 생각을 하고 있는지도 굉장히 중요하다고 봅니다.

그래서 저는 어닝콜이나 가이던스를 직접 해당 내용을 문장 하나씩 실제로 어떤 식의 내용이 서로 주고 받아졌는지 확인하는데요.

쉽습니다.

구글 검색하실때, "해당 기업명 + earning call + transcript" 이렇게 검색하시면 됩니다. 전체 내용보는데는 보통 10-20분 걸리고, 여기서 아이디어 도출하고 생각 정리하는데도는 보통 30-40분, 그리고 여러 기업들 있으니 보통 8시간 정도 걸리네요. 이정도로 내용 정리하다보면 생각보다 많이 배워갑니다.

리서치 워크플로우

  1. 주말에 몰아서: 평일 어닝콜이 많으면 주말에 시간을 내어 놓친 기업들을 정리
  2. 직접 트랜스크립트 읽기: AI 요약에 의존하지 않고 실제 어닝콜 트랜스크립트를 직접 확인
  3. 기관 투자자 질문 분석: 뱅크오브아메리카, Jane Street, Citadel 등 기관 투자자들의 질문을 통해 해당 기업의 핵심 이슈 파악
  4. CEO 마인드 확인: CEO의 발언과 생각을 직접 분석
  5. 검색 팁: Google에서 "[기업명] earning call transcript" 로 검색

소요 시간

단계시간
전체 내용 리뷰10-20분
아이디어 도출 및 정리30-40분
여러 기업 총합~8시간
