OpenClaw에 Google Embedding 2 연결하기 — 메모리 검색 대폭 향상

원본: https://www.threads.com/@funcodingdavelee/post/DV46p1nEs5f

요약

OpenClaw에 Google Embedding 2 (Gemini API) 를 연결하면 에이전트의 메모리 검색 품질이 크게 향상된다는 실사용 후기. 파일 458개를 통째로 기억하며, 이전 임베딩 대비 질문 의도를 훨씬 정확하게 파악한다.

핵심 포인트

  • 설정 1줄이면 끝 — Gemini API 키 하나로 연결
  • 무료 — 분당 60회까지 공짜 (Gemini API 무료 티어)
  • 검색 품질 향상: 이전 임베딩은 관련 없는 결과가 섞였는데, Google Embedding 2는 질문 의도를 정확히 이해
  • 458개 파일 전체를 메모리로 인덱싱 — "전에 한 거 다시 해줘" 류의 요청에 정확히 대응
  • 빠른 검색 속도

실용적 인사이트

  • OpenClaw 메모리 시스템의 임베딩 모델 교체만으로 체감 품질이 크게 달라짐
  • Gemini API 무료 티어가 개인 사용에 충분한 수준
  • "에이전트가 나보다 내 일정을 더 잘 기억하는" 수준까지 도달 가능

참고

현재 자비스 시스템은 OpenAI text-embedding-3-small 사용 중 (2026-02-14 설정).

Google Embedding 2로 교체 시 비용 절감(무료) + 검색 품질 향상 가능성이 있음.
