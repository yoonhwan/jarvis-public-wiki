앱 UI 메뉴판 (app-menu) — Giting 스킬

본문 (Main Post, OG meta 추출)

「아래에서 올라오는 그거 있잖아」 하고 AI 에게 앱 화면을 시키면 매번 다른 게 나옴.
그 판은 바텀시트.
「밀면 나오는 삭제 버튼」은 스와이프 액션.
「위에서 당기면 새로고침」은 Pull to Refresh.
「회색 네모 반짝」은 스켈레톤.
이름으로 시키면 AI 가 실제 부품을 바로 집음.
바텀시트면 SwiftUI 는 .presentationDetents, Flutter 는 showModalBottomSheet.
모바일 앱 UI 를 이렇게 정리한 메뉴판, 8코스 72항목.
부르는 말, 정식 이름, 시키는 문장, 프레임워크 부품까지 한 줄씩.
웹 UI 메뉴판의 앱 판.

무엇인가 — app-menu 스킬 (giting.kr)

모바일 앱 UI를 "말"이 아니라 "이름"으로 AI에게 시킬 수 있게 해주는 72항목 사전. 웹 UI 사전인 ui-menu의 모바일판.

핵심 아이디어

"아래에서 올라오는 그거 있잖아"가 바텀시트라는 걸 아는 순간, 손잡이·높이 단계(반높이/전체높이)·바깥 탭 닫기까지 한 번에 따라온다. 이 사전은 생성기가 아니라 이름·요청 문장·빠짐 점검표를 준다 — 코드는 사람이 짠다.

8코스 구성 예시

코스항목수대표 예시
① 화면 뼈대8앱바(App Bar), 하단 탭바(Tab Bar → SwiftUI TabView/Flutter BottomNavigationBar/RN Tab.Navigator)
② 화면 이동8뒤로가기, 세그먼티드 컨트롤(Picker(.segmented)/SegmentedButton), 드로어(Drawer)
③ 목록8섹션 헤더, 카드(Card)
④ 입력받는 것12비밀번호 토글, 체크박스
⑤ 골라 넣는 것7별점(Rating), 수량 스텝퍼(Stepper)
⑥ 누르는 것11프라이머리/세컨더리/디스트럭티브 버튼, 메뉴(Menu/PopupMenuButton), FAB(FloatingActionButton), 탭 타깃 44pt
⑦ 위에 띄우는 것9팝오버(Popover), 툴팁(Tooltip)
⑧ 상태·표시9아바타(Avatar), 상태 점(Status Dot)

각 항목은 "부르는 말(별칭) → 정식 이름 → AI에게 시키는 문장 예시 → 네이티브 컴포넌트명"까지 한 줄로 연결되어 있다.

웹/앱 관례 차이 짚음

같은 단어라도 웹과 앱에서 쓰임이 다른 경우를 구분해준다:

  • 모달: 웹은 중앙 팝업, 앱은 아래서 올라오는 풀스크린
  • 셀렉트: 웹은 드롭다운, 앱은 시트(바텀시트)로 열림
  • 호버: 웹은 마우스 오버, 앱은 길게 누르기(long press)

빠짐 점검 체크리스트

모바일 개발에서 자주 빠뜨리는 것들을 체크리스트로 제공: 세이프 에어리어, 탭 타깃 44pt, 엠프티 스테이트, 로딩 버튼 잠금 등.
