hwp2md — HWP(한글) 문서를 Markdown으로 변환하는 CLI 도구

원본: https://www.threads.com/@feelfreeai/post/DV5PWaMjMOI
GitHub: https://github.com/roboco-io/hwp2md

요약

한국에서 피할 수 없는 HWP 파일을 명령어 한 줄로 Markdown으로 변환하는 Go 기반 CLI 도구. 단순 텍스트 추출을 넘어 복잡한 표나 구조를 최대한 살리며, 선택적으로 LLM을 연동해 가독성 높은 Markdown을 생성한다.

핵심 포인트

  • HWPX + HWP 5.x (2002~2022) 모두 지원
  • 로컬 CLI 기반 — 사내망/보안 이슈 해결 (웹 변환기 불필요)
  • 2단계 파이프라인 아키텍처:
    • Stage 1 (Parser): HWP → 중간 표현(IR) → 기본 Markdown
    • Stage 2 (LLM, 선택적): IR → LLM → 가독성 향상된 Markdown
  • LLM 프로바이더 자유 선택: Anthropic(Claude), OpenAI(GPT), Google(Gemini), Upstage(Solar), Ollama(로컬)
  • CI/CD 파이프라인이나 대량 문서 마이그레이션에 바로 투입 가능
  • Claude Code를 활용한 바이브 코딩으로 개발됨

설치

# Go 설치
go install github.com/roboco-io/hwp2md/cmd/hwp2md@latest

# 또는 GitHub Releases에서 바이너리 다운로드 (macOS Apple Silicon)
# hwp2md_*_darwin_arm64.tar.gz

사용법

# 기본 변환 (Stage 1만)
hwp2md document.hwpx -o output.md
hwp2md document.hwp -o output.md

# LLM 연동 변환 (Stage 1 + Stage 2)
export ANTHROPIC_API_KEY="your-key"
hwp2md convert document.hwpx --llm

# 다른 LLM 프로바이더
hwp2md convert document.hwpx --llm --provider openai
hwp2md convert document.hwpx --llm --provider ollama --model llama3.2

# Upstage Document Parse (OCR 기반, 복잡한 레이아웃용)
export UPSTAGE_API_KEY="your-key"
hwp2md document.hwpx --parser upstage

# JSON IR 추출
hwp2md extract document.hwpx -o output.json

활용 시나리오

  • 사내 레거시 HWP 문서 → Git/Notion 마이그레이션
  • CI/CD 파이프라인에서 대량 문서 자동 변환
  • 보안 이슈로 웹 변환기 사용이 어려운 환경
  • LLM 연동으로 복잡한 표/구조를 가독성 높게 변환

기술 스택

  • 언어: Go 1.24+
  • 아키텍처: 2단계 파이프라인 (Parser → LLM)
  • 개발 방식: Claude Code 바이브 코딩
  • CI/CD: GitHub Actions + pre-commit/pre-push hooks
