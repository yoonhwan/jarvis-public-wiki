📦 설치법

# ① 마켓에서
/plugins → 검색 → 설치

# ② GitHub에서
claude plugin add <github-url>

# ③ 스킬만
# GitHub에서 SKILL.md 복사 → .claude/skills/에 붙여넣기

# 스코프 설정
--scope user      # 내 모든 프로젝트 (기본값)
--scope project   # 팀원 전체 공유
--scope local     # 나만, 이 프로젝트에서만

# 예시
claude plugin install superpowers --scope project
