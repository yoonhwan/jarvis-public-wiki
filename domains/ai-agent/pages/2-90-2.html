새벽 2시, 아무도 없는 사무실에서 화면 깨진 노트북 한 대가 카톡 대화방 90개를 정리합니다.

업무방이 90개를 넘으니 사람이 하나씩 열어보는 건 불가능했습니다. 매일 새벽 자동으로 전체 대화를 수집하고, 방마다 CSV로 정리하고, 사진까지 챙긴 뒤 스스로 종료합니다. 모니터도 없고 사람도 없습니다.

읽기 전용이고 데이터는 전부 로컬에 둡니다. 오픈소스로 공개했습니다.

프로젝트 요약 — kakao-auto

KakaoTalk Windows Auto Chat Collector & Archiver — Windows PC에 켜둔 카카오톡의 모든 대화방을 매일 새벽 자동으로 앱 자체 Ctrl+S 내보내기를 이용해 수집, 방마다 CSV 1개로 정리하고 사진까지 백업하는 읽기 전용·완전 오프라인 도구.
항목내용
플랫폼Windows 전용 (Python 불필요, 설치 실행파일 제공)
설치GitHub Releases의 KakaoAuto-Setup.exe 다운로드 → 실행 (Windows Defender 경고 시 "추가 정보 → 실행")
동작 방식KakaoTalk을 Chats 탭에 열어두고 Enter → collect → consolidate → CSV 생성 → 사진 백업 파이프라인 실행
자동화메뉴 11로 매일 02:00 자동 실행 작업 등록 (관리자 권한 불필요, 절전 비활성화, 모니터 불필요 — 화면 꺼진 노트북에서도 동작 검증됨)
출력sharedir(기본 C:/kakaoshare) 하위에 csv/<room>/<room>.csv, media/(사진만, 이모티콘·스티커 제외), kakao.db(SQLite)
CSV 컬럼room, date, time, datetime, sender, message (UTF-8-SIG, Excel/pandas 바로 호환)
부가 기능대시보드(응답 대기 현황·14일 히트맵), 전문 검색(오프라인 HTML), 관계 그래프, Excel 내보내기, 정규식 기반 금액/약속/계좌 추출, 사진 백업
라이선스/책임비공식·개인 도구, Kakao Corp와 무관. KakaoTalk 이용약관 위반 소지 있음 (계정 제한 가능) — 저자는 이를 명시적으로 고지. PIPA 등 개인정보 관련 책임은 사용자에게 있음
