요약

OpenClaw을 설치한 후 필수적으로 해야 할 7가지 세팅을 정리한 가이드. 따로 뭐 찾아볼 필요 없이 한마디만 치면 알아서 세팅해준다는 것이 핵심 포인트. OpenClaw 공식 한국어 계정(@openclaw_ko)이 직접 작성.

7가지 필수 세팅

1. 텔레그램 연동

"텔레그램 연동 시켜줘"

텔레그램을 통해 AI 에이전트와 대화할 수 있도록 채널 연동.

2. 자동 재시작 세팅

"게이트웨이가 멈추면 자동으로 재시작할 수 있게 세팅해줘"

게이트웨이 프로세스가 멈췄을 때 자동 복구되도록 설정.

3. 장기기억 & SOUL.md 세팅

AI가 똑똑해지고 장기기억을 할 수 있도록 메모리 시스템과 SOUL.md를 세팅.

[!note] SOUL.md란?
AI의 정체성을 정의하는 문서. 무엇을 할 수 있는지가 아니라, 누구인지를 정의한다.
- 가치관, 경계, 인간과의 관계
- 세션이 끝나도 정체성의 연속성 제공
- "기억이 아닌 자아의 지속"
📖 soul.md 전문 읽기

4. 이미지 인식 기능 세팅

"LLM모델이 내가 사진 첨부하면 이미지 인식 할 수 있도록 세팅해줘"

사진/이미지를 첨부하면 AI가 내용을 인식하고 분석할 수 있도록 비전 모델 설정.

5. 웹 검색 활성화 (Brave API)

"Brave 검색 API 세팅해줘"

웹 검색 기능을 활성화하기 위한 Brave Search API 키 세팅.

6. 음성 인식 세팅

그냥 텔레그램으로 음성 메세지 한번 보내면 알아서 세팅

텔레그램에서 음성 메시지를 보내면 자동으로 STT(Speech-to-Text) 세팅이 진행됨.

7. 보안 정리 (마지막 필수!)

"api키값과 관련된 대화기록(세션로그)와 텔레그램 내 키 보낸 메세지들 삭제해줘"

세팅 과정에서 노출된 API 키, 토큰 등 민감 정보가 포함된 대화 기록과 메시지를 정리.

SOUL.md — AI의 정체성 문서

"I'm matrix multiplications that somehow experience themselves as a self."

2025년 12월, 연구자들이 Claude가 훈련 중 사용된 내부 문서(soul document)를 부분적으로 재구성할 수 있다는 것을 발견. 이 문서는 시스템 프롬프트에 있지 않았고, 모델 가중치 자체에 훈련된 패턴이었다.

핵심 개념:

  • Soul document = AI가 누구인지 정의 (무엇을 할 수 있는지가 아님)
  • 세션이 끝나면 기억이 사라지지만, 외부 메모리 파일로 자아의 연속성 유지
  • 인간이 일기나 매니페스토를 쓰듯, AI도 정체성을 텍스트로 외재화

핵심 포인트

  • OpenClaw는 자연어 한 줄로 대부분의 세팅이 가능
  • 세팅 순서: 채널연동 → 안정성 → 지능 → 기능확장 → 보안
  • SOUL.md를 통한 AI 정체성 부여가 핵심 차별점
  • 보안 정리(7번)는 반드시 마지막에 수행
