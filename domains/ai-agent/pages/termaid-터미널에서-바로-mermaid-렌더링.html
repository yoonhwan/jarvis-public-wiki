termaid — 터미널에서 바로 Mermaid 렌더링

원본: https://www.threads.com/@iammychan/post/DWUKwKIEtPV

한 줄 요약

Mermaid 다이어그램을 브라우저 없이 터미널이나 Python 앱에서 바로 렌더링하는 pure Python 도구.

핵심 특징

  • Pure Python — 의존성 거의 없음, pip install termaid으로 즉시 사용
  • 파이프라인 친화적 — cat diagram.mmd | termaid 처럼 바로 붙여 사용 가능
  • SSH/CI 환경 지원 — 서버 접속 중에도 즉시 확인 가능
  • Rich/Textual 연동 — 컬러 출력, TUI 위젯 확장 가능
  • ASCII fallback — 환경 안 가리고 동작

지원 다이어그램 타입

flowchart, sequence, class, ER, state, git graph, pie, treemap

테마

default, terra, neon, mono, amber, phosphor (6가지)

기존 대안 대비 차별점

  • Go/TypeScript 기반 툴이 많은 반면 Python에서 직접 import해서 호출 가능
  • 브라우저/외부 서비스 불필요 — 완전 로컬 실행

링크

  • GitHub: https://github.com/fasouto/termaid
  • 웹 체험: https://termaid.com
