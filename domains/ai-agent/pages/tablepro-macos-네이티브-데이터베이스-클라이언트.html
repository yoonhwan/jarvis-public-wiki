TablePro — macOS 네이티브 데이터베이스 클라이언트

원본: https://www.threads.com/@iammychan/post/DV04LQKkoPK

개요

TablePro는 macOS 전용 네이티브 데이터베이스 클라이언트로, AI 어시스턴트가 내장되어 있다. SQL 자동완성, 인라인 편집, AI 보조 기능이 핵심.

지원 데이터베이스

  • MySQL
  • MariaDB
  • PostgreSQL
  • SQLite
  • MongoDB
  • Redis
  • SQL Server
  • Redshift

핵심 기능

  • SQL 에디터: 자동완성 지원
  • 인라인 편집: 테이블 데이터 직접 수정
  • AI 어시스턴트: 쿼리 작성 시 AI 보조 (막힐 때 바로 도움)
  • 네이티브 macOS 앱: Swift 기반, 빠른 성능

설치

brew install --cask tablepro

또는 GitHub Releases에서 DMG 직접 다운로드.

소감 (원문 요약)

"맥용 DB 툴 아직도 안 쓰면 손해. DB 붙이고, 수정하고, 쿼리 짜는 시간 확 줄여준다. 특히 SQL 자주 만지는 사람은 진짜 편함."

무료로 문서 확인 가능하고, macOS 앱으로 바로 설치해서 쓸 수 있다.
