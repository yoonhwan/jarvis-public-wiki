본문 (Main Post)

마이크로소프트에서 스킬 개선 오픈소스가 나와서 점심 시간을 반납하고 알아보았다.

(주의: 개발자 아님, 전문가 아님 — 반드시 검증하여 쓸 것)

작동 방식 (추정)

  1. 과거 Codex·Claude 작업 기록을 읽음
  2. 현재 SKILL.md로 그 작업을 다시 실행함
  3. 잘못된 부분이나 빠진 지시를 찾음
  4. 수정안을 만듦
  5. 검증 점수가 좋아질 때만 수정안을 임시 보관함
  6. 사용자가 확인한 뒤 adopt를 실행해야 실제 SKILL.md에 반영됨

실제 사용 결과 — 검증 항목

실제 사용해 본 결과 다음 항목으로 검증할 수 있었다.

  1. 원본 Claude JSONL을 수정하지 않는가
  2. 실제 파일 상태를 다시 읽는가
  3. 실패 시 실행 명령·원인·다음 조치를 보고하는가
  4. Codex 대화 목록에 파일이 자동으로 나타난다고 잘못 말하지 않는가

추천 사용법

처음에는 dry-run으로 시험하고, 수정안 확인 후에만 실제 적용하는 것을 추천한다.

핵심 요약

  • Codex/Claude의 과거 작업 로그를 근거로 SKILL.md를 자동 점검·개선하는 도구
  • 검증 점수가 개선될 때만 수정안을 임시 보관 → 사용자 adopt 승인 후에만 반영 (안전장치)
  • 원본 로그(JSONL)는 건드리지 않고, dry-run 워크플로우 지향
