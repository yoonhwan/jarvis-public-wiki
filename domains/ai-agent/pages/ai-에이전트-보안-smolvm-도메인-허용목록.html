핵심 내용

격리된 환경(VM)을 제공하는 건 이제 기본이지만, 외부 통신 제어가 핵심이라는 내용.

오픈소스 프로젝트 SmolVM의 도메인 허용 목록(allowlist) 기능을 통해 에이전트가 딱 필요한 곳(내 API, GitHub, Stripe 등)만 접근하도록 제한할 수 있음.

주요 포인트

  • 신뢰할 수 없는 코드 실행 시 Blast radius(폭발 반경) 를 획기적으로 줄일 수 있음
  • 단순 격리를 넘어 프로그래밍 가능한 보안 경계 직접 설정
  • 코드 예시 + 개념 다이어그램 포함
