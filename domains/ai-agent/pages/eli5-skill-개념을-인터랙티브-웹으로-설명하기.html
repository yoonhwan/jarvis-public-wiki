본문 (Main Post)

👀 요즘 Anthropic 내부에서 많이 쓴다는 /eli5 Skill이 웹에서 화제가 되고 있음. 실시간 검색에서도 별도 화제 포스트로 묶였고, Anthropic 커뮤니티 GitHub에도 실제 Skill이 공개되어 있는데 핵심은 놀랄 정도로 단순함.

핵심 지침:

"아무것도 모르는 사람에게 설명하듯, 큰 그림과 적은 글자를 사용한 HTML Artifact로 설명해라."

즉, 접근 방식을 바꾸는 것:

❌ 기존✅ eli5 방식
어려운 개념 → Markdown 장문 설명어려운 개념 → 큰 그림 → 관계도 → 화살표 → 짧은 설명 → 직접 눌러보며 이해

Anthropic도 공식 글에서 AI Agent의 출력이 점점 복잡해지면서 Markdown만으로는 제한적이고, HTML을 이용하면 시각화·색상·다이어그램·인터랙션을 훨씬 잘 표현할 수 있다고 설명했음.

ChatGPT에서 한 단계 더

HTML 파일을 만들어 달라고 하지 않고, "대화창 안에서 바로 실행되는 인터랙티브 웹으로 설명해줘" 라고 요청하는 것.

예: /eli5 그래프 엔지니어링 뒤에 아래 프롬프트를 붙임.

실전 프롬프트

다음 개념을 ELI5 방식으로 설명해줘.

조건:
• 이 주제를 전혀 모르는 사람을 기준으로 설명
• 긴 Markdown 설명은 최소화
• 큰 그림, 도형, 관계도, 화살표 중심
• 단순히 이미지를 보여주는 것이 아니라 인터랙티브하게 구성
• 버튼, 노드, 카드 등을 직접 눌러보며 개념을 탐색할 수 있게 만들기
• 단계별 흐름이 있다면 직접 선택하면서 변화가 보이게 하기
• 비교할 개념이 있다면 직접 눌러 차이를 확인할 수 있게 하기
• 모바일에서도 보기 편하게 구성
• 별도의 HTML 파일을 주지 말고 ChatGPT 대화 안에서
  바로 실행되는 인터랙티브 웹으로 표현

주제:
[여기에 알고 싶은 내용]

효과 예시 (그래프 엔지니어링)

단순히 "Graph의 Node는 무엇이고 Edge는 무엇입니다"라고 읽는 게 아니라:

[민수] ─ 사용 ─ [Python]
  │
 소속
  ↓
 [A사]

같은 구조를 실제로 눌러보면서

  • "아, Node는 이것이고"
  • "Edge는 이 관계구나"
  • "A사와 Python은 민수를 통해 연결되는구나"

를 직접 탐색하며 이해할 수 있음.
