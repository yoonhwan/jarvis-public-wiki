17살 솔로 개발자, 모델 머징 아키텍처 'Fusion'으로 Fuse-1-Lite 공개

본문 (Main Post)

17살 솔로 개발자가 새로운 모델 아키텍처 'Fusion'으로 Fuse-1-Lite를 공개했다. LiquidAI의 LFM 2.5-2.6B에 Qwen 3.6-35B-A3B의 코딩 전문가(expert) 960개를 융합한 MoE 모델이다.

항목내용
모델명Fuse-1-Lite
아키텍처Fusion (신규)
베이스LiquidAI LFM 2.5-2.6B
융합 소스Qwen 3.6-35B-A3B 코딩 전문가 960개
파라미터5.72B
성능Qwen 3.6-35B-A3B에 근접 (크기는 1/5 수준)
개발 기간9주, 32번 실패 끝 완성
포맷MLX 공개 → 애플 실리콘에서 바로 실행
  • MiniMax M3, DeepSeek V4 Flash 기반 경량 모델도 이미 제작 완료.
  • MergeKit 개발자 막심 라본(Maxime Labonne): "초기 모델 머징 열풍이 떠오른다"고 평가.
  • 수천억 원 규모 학습 인프라 없이도 오픈웨이트 모델을 조합해 성능을 끌어올리는 시도가 개인 개발자 수준에서 나오기 시작.

댓글 (Other Users)

⚠️ 검증 지적 (핵심): 파일을 직접 열어본 사용자의 분석

  • 전문가 가중치 SHA256이 Qwen3.6-35B-A3B 원본과 바이트 단위로 일치 → 이식(porting)은 진짜.
  • 다만 성능 주장은 근거 없음 — 카드 model-index의 HumanEval 값이 문자 그대로 "TBD".
  • 실제 동작: 30개 층 중 11개만 활성, clamp(max=0.1) 때문에 그 11개가 전부 동일 값으로 잘림. 나머지 19개 층 33%(3.8GB)는 로드만 되고 실행 안 됨.
  • 원인 추정: 도너에서 전문가가 쓰던 postattentionlayernorm을 안 가져온 것으로 보임. Qwen에서 전문가들은 정규화된 입력(RMS 0.19~0.46)을 받도록 학습됐는데, 여기선 정규화 안 된 층 출력을 그대로 입력. 폭이 같다고 기저가 같은 건 아니라서 스칼라 std 비율만으로는 안 맞을 것.
  • "방향 자체는 흥미롭다. 벤치 나오면 다시 보고 싶다."
