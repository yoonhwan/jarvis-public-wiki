공무원이 만든 법제처 국가법령정보 MCP

법제처 42개 API를 10개 도구로. 법령, 판례, 행정규칙, 자치법규, 조약, 해석례(국세청 포함) + LLM 환각 방지 인용 검증(실존+내용) + 조문 영향 그래프 + 시점 비교 자동 diff + 이럴 땐 이렇게 — 5단계 안내 + 판례 생사 확인(Citator) + 행위시법 판단 + 조례 정비 레이더를 AI 어시스턴트나 터미널에서 바로 사용.

원본 코드: https://github.com/chrisryugj/korean-law-mcp

핵심 기능 정리

도구 / 기능설명
통합 검색법령·판례·행정규칙·자치법규·조약·해석례(국세청 포함) 조회
verify_citations (인용 검증)LLM 환각 방지 — 조문 실존 확인 + 제목·내용 일치까지 대조(CONTENT_MISMATCH 탐지)
impact_map (조문 영향 그래프)조문 한 줄의 파급효과를 판례·헌재결정·해석·자치법규까지 역/정방향 탐색 → mermaid 그래프 자동 생성
시점 비교 (자동 diff)특정 시점 조문 vs 현행 비교
applicable_law (행위시법 판단)기준일에 시행 중이던 버전(MST) 특정 + 부칙 경과규정 자동 발췌
cite_check (판례 생사 확인)한국형 Shepard's Citator — 후속 판례 역추적으로 변경·폐기 신호 감지
ordinance_radar (조례 정비 레이더)상위법 개정 대비 조례 정비 검토 대상 자동 플래그
5단계 안내 ("이럴 땐 이렇게")시나리오별 단계별 가이드

인사이트

  • 법제처 Open API를 실무 관점(공무원·법무팀·연구자)에서 재조립한 사례. 단순 API 래핑이 아니라 LLM이 법률 도메인에서 저지르는 전형적 오류(존재하지 않는 조문/제목 환각, 변경·폐기된 판례를 유효한 것처럼 인용, 현행법 오적용)를 구조적으로 차단하는 데 초점.
  • 도구 통폐합(19→9)으로 MCP ListTools 컨텍스트를 절반으로 줄인 최적화가 실용적 참고점.

유즈케이스 10

  1. 계약서 리스크 검토 자동화 — 계약 조항에 인용된 법령·조문을 verify_citations로 실존+내용 대조해, 존재하지 않거나 개정으로 문구가 바뀐 조항을 즉시 플래그. 법무팀 검토 1차 필터.
  2. AI 법률 답변 환각 차단 레이어 — 사내 법률 챗봇 뒤에 붙여, LLM이 "○○법 제△조" 인용할 때마다 실제 조문과 대조(CONTENT_MISMATCH 탐지). 잘못된 조문 인용을 사용자에게 내보내기 전에 차단.
  3. 과거 사건 적용법 판단(행위시법) — applicable_law로 행위 시점에 시행 중이던 버전(MST) 특정 + 부칙 경과규정 자동 발췌. 소급·경과 이슈 사건에서 적용 버전 근거 확보.
  4. 판례 유효성 실시간 검증(Citator) — 준비서면에 인용할 판례를 cite_check로 후속 판례 역추적해 변경·폐기·재확인 신호 감지. "죽은 판례" 인용 방지.
  5. 법 개정 파급효과 분석 — impact_map으로 개정 대상 조문이 연결된 판례·헌재결정·해석례·자치법규까지 그래프(mermaid)로 시각화. 입법·개정 영향평가 보고서 초안.
  6. 조례 정비 레이더(지자체 실무) — ordinance_radar로 상위법령 개정 시 정비 필요 조례를 자동 플래그. 지자체 법무 담당의 상시 모니터링.
  7. 조문 시점 비교 diff — 특정 시점 조문 vs 현행 자동 diff. 조항 변경 이력 추적 → 컴플라이언스 변경 이력 문서화.
  8. 세무 실무 해석례 검색 — 국세청 해석례 포함 통합 검색으로 세무 이슈의 유권해석 근거 즉시 확보. 세무사·회계법인 리서치 시간 단축.
  9. 민원/상담 5단계 안내 봇 — "이럴 땐 이렇게" 시나리오 가이드를 시민 민원 챗봇에 연결. 절차·근거 법령을 단계별 안내하는 공공 서비스.
  10. 개발자 CLI 통합 리서치 — Claude Desktop / Cursor / 터미널에서 코딩 중 규제·컴플라이언스 조문 바로 조회(예: 개인정보보호법 확인하며 코드 작성).

핵심 아이디어 요약

  • 단순 API 래핑이 아님: 법률 도메인 LLM의 3대 오류(조문 환각 / 죽은 판례 인용 / 현행법 오적용)를 구조적으로 차단하는 게 진짜 가치.
  • 적용층별 침투: 법무팀(리스크 검토) → 지자체(조례 정비) → 세무(해석례) → 개발자(CLI)까지 수요층이 넓음.
  • AI 신뢰성 인프라: 리걸테크가 "환각 없는 법률 AI"를 만들 때 검증 백엔드로 그대로 얹을 수 있는 오픈소스 부품.
