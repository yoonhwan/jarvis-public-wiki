원문 (Threads 본문)

GitHub 스타 1.6만 개. GPU 없이 한국어 음성까지 생성하는 오픈소스 AI가 나왔어요.
이름은 'KittenTTS 2'.
한국어를 포함한 20개 언어를 지원하고, 47개 기본 음성에 감정 표현 기능까지 제공합니다.
더 흥미로운 건 음성 복제예요. 5~30초 분량의 목소리 샘플만 있으면 별도 학습 없이 해당 목소리로 새로운 문장을 읽게 할 수 있습니다.
1.7B 파라미터 모델이지만 양자화된 가중치는 약 506MB이고, GPU 없이 CPU에서도 실행할 수 있어요.
영상 내레이션, 오디오북, AI 음성 비서 등에 활용하기 좋겠네요. 다만 한국어 발음 품질은 직접 테스트해 보는 게 좋겠습니다.
https://github.com/KittenML/KittenTTS

※ SSR 추출 시 이 포스트는 pk-block/caption 필드가 없는 "순수 외부링크 공유형" 포스트였음 (og:description에 본문 전문이 그대로 담겨 있어 그대로 사용).

모델 상세 (GitHub README 보강)

주요 기능

  • 음성 복제: 5~30초 단일 화자 샘플로 클로닝. Transcript 생략 시 Whisper가 자동 채움.
  • 감정 표현(Beta): [emotion] 태그, <event> 인라인 태그, (((emphasis))) 강조 구문 지원 — 총 10개 감정, 10개 음성 이벤트 인식.
  • 긴 텍스트 처리: 문장 단위 청크 분할 + 이음매 무음 트리밍/페이드 처리, 스트리밍 생성 지원(generate_stream).
  • CPU 최적화: 자체 llama.cpp 포크(kitten-tts-2-cpp)로 CPU 실시간 추론. Apple Silicon에서는 MLX 백엔드로 수 배 가속.
  • vLLM 지원: NVIDIA Ampere 이상 GPU에서 4bit(w4a16) 양자화 추론 가능.

빠른 시작

pip install kittenml
from kittenml import KittenTTS
import soundfile as sf

m = KittenTTS("KittenML/kitten-tts-2")
audio = m.generate("Hi! umm.. how are you, I guess?", voice="WeatherPresenterCheerful")
sf.write("output.wav", audio, m.sample_rate)

음성 복제 예시:

audio = m.generate("This is my own voice, cloned.", reference="my_voice.wav")

측정치: 클로닝한 목소리는 자기 레퍼런스 대비 화자 유사도 0.49~0.72, 다른 37개 목소리 대비 0.01~0.18, 미학습 녹음 클로닝 시 0.81.

Mac(Apple Silicon)에서 실행

pip install "kittenml[mlx]"
m = KittenTTS("KittenML/kitten-tts-2", backend="mlx")

→ 로컬 MLX 서빙 환경에 바로 적용 가능 (옵시디언 사용자 환경 메모: MLX 로컬 서빙 선호).

주의사항

  • 라이선스 분리: 코드(Apache 2.0)와 모델 가중치(Stellon Labs Community License)의 라이선스가 다름 — 상업적 활용 전 모델 라이선스 별도 확인 필요.
  • 한국어 발음 품질은 원문 작성자도 "직접 테스트 권장"이라고 언급 — 검증된 벤치마크 수치는 없음.
  • 짧은 텍스트(약 380자 미만)는 스트리밍이 동작하지 않고 generate와 동일하게 단일 청크로 처리됨.
