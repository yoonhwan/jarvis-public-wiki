의사결정 모델도 멀티모달로 진화… vLLM·Cloudflare 오픈소스 모델 Decision 3.0, Clef-omni 공개

류내원(@won.wizard)님이 공유한 AI타임스 기사 스크랩. "의사결정 모델(decision model)" — 자연어 답변 대신 선택지별 확률값을 반환하는 모델 — 이 텍스트 전용에서 이미지·오디오·비디오까지 처리하는 멀티모달로 빠르게 진화하는 트렌드를 다룬 기사.

모델개발사크기입력특징

본문 (Main Post)

vLLM Semantic Router 개발팀은 텍스트와 JSON뿐만 아니라 이미지까지 직접 분석할 수 있는 멀티모달 의사결정 모델 제품군 'Decision 3.0'을 오픈소스로 공개
기존 의사결정 모델이 주로 텍스트와 구조화된 데이터에 의존했던 것과 달리, 디시전 3.0은 이미지 속 정보를 직접 처리해 AI 에이전트의 판단과 요청 분류, 안전성 검증을 간소화한 것이 특징
0.8B부터 27B까지 총 5개 크기로 구성. 모두 허깅페이스를 통해 Apache-2.0 오픈소스 라이선스 공개
디시전 3.0은 모든 모델에 비전 인코더를 내장해 중간 단계를 줄였고, 모든 질문에 대한 판단 결과는 확률값으로 제공
알리바바의 Qwen 계열 모델을 기반으로 미세조정
#Decision3 #Clefomni #의사결정모델 #wonwizard

댓글 스레드 (Reply Thread — 작성자 won.wizard 추가 내용)

자체 평가 결과에 따르면, d3 모델은 텍스트 평가에서 64.1점, 비전 평가에서 71.6점을 기록해 퍼플렉시티의 Decider v1.1보다 높은 점수. 모델 크기를 줄이면서도 약 90억개 매개변수의 d3-플래시가 텍스트 평가에서 이전 세대의 270억개 매개변수급 모델을 앞서는 등 효율성을 입증
이미지 기반 UI 분석, 콘텐츠 안전성 검증 등 다양한 분야에 활용 가능. 특히 이미지와 텍스트가 결합된 입력을 처리해야 하는 서비스
Cloudflare 역시 텍스트, 이미지, 오디오, 비디오를 한 번에 처리하는 멀티모달 의사결정 모델 Clef-omni를 선보이며 트렌드에 합류
총 300억개 매개변수 중 실제 추론에 활용되는 매개변수가 30억개인 전문가 혼합(MoE) 구조 채택. 허깅페이스를 통해 오픈 가중치 제공
여러 형태의 데이터를 한 번에 분석해 의사결정 결과를 확률값으로 반환

원문 기사 전문 요약 (AI타임스, 박찬 기자)

Decision 3.0 (vLLM Semantic Router)

  • 공개일: 2026-10-11 (현지시간)
  • 라인업: d3-라이트(lite) → d3-나노(nano) → d3-미니(mini) → d3-플래시(flash) → d3 (최대형, 약 260억 파라미터)
  • 나머지 4개 모델은 약 8억~84억 파라미터
  • PNG/JPEG/WebP 이미지, 최대 160만 픽셀 해상도, 한 요청에 다중 이미지 지원
  • Qwen 계열(Qwen3.8-27B 기반) 미세조정
  • 평가 결과: d3 텍스트 64.1점 / 비전 71.6점 — Perplexity Decider v1.1 상회
  • d3-플래시(약 90억 파라미터)가 이전 세대 270억 파라미터급 모델을 텍스트 평가에서 앞서는 효율성 입증
  • 활용처: AI 에이전트 요청 분류·모델 선택, 이미지 기반 UI 분석, 콘텐츠 안전성 검증

Clef-omni (Cloudflare)

  • 공개일: 2026-10-09
  • Qwen3-Omni-30B-A3B-Instruct 기반 post-training (TTS 출력 경로 제거, LoRA 어댑터 + label-smoothed CE + Brier score 학습)
  • MoE 구조: 총 300억 파라미터 중 30억 활성
  • Workers AI에서 @cf/cloudflare/clef-omni로 서빙, 가중치는 Hugging Face(Cloudflare/clef-omni) 공개 (Apache-2.0)
  • 입력: 텍스트 + 이미지 최대 4개 + 오디오 클립 최대 4개 + 비디오 최대 2개 (요청당 질문 최대 64개)
  • 처리 속도: 텍스트 약 130ms, 이미지 약 150ms(중앙값), 21초 분량 음성 포함 영상 약 1.5초
  • 의도 분류: BANKING77 94.8 / CLINC150+OOS 97.7 (매크로 F1, Clef 계열 중 최고)
  • 다만 복잡 추론·워크플로 평가에서는 기존 Clef보다 낮음 — GPQA Diamond 47.4점 (Jev 78.3점 대비 열위)
  • 시사점: 다양한 입력 형식 동시 처리 능력과 복잡 추론 성능이 반드시 비례하지 않음
