LangSmith CLI

에이전트 네이티브 CLI — 코딩 에이전트(와 개발자)가 LangSmith 내 모든 것을 처리하는 빌딩블록

기능

  • 트레이스 조회 (fetch traces)
  • 데이터셋 큐레이션 (curate datasets)
  • 실험 실행 (run experiments)
  • 완전 터미널 기반 LangSmith 탐색 — 코딩 에이전트가 터미널만으로 모든 것 처리 가능

설치

curl -sSL https://raw.githubusercontent.com/langchain-ai/langsmith-cli/main/scripts/install.sh | sh

GitHub: https://github.com/langchain-ai/langsmith-cli

3개 LangSmith Skills 상세

Skill 1: trace

기존 코드에 트레이싱 추가 + 트레이스 조회

  • 에이전트 실행 추적
  • 트레이스 데이터 쿼리

Skill 2: dataset

테스트 데이터셋 구축

  • 예제 데이터셋 생성
  • 트레이스에서 데이터셋 빌드

Skill 3: evaluator

에이전트 성능 평가

  • 데이터셋 기반 평가 실행
  • 에이전트 정확도 검증

에이전트 자기 개선 루프 (핵심 가치!)

LangSmith 스킬이 가능하게 하는 덕목 사이클(Virtuous Cycle):

1. 코딩 에이전트가 LangChain + LangSmith 스킬 사용
   ↓
2. 에이전트 자신의 실행에 트레이싱 로직 추가
   ↓
3. 생성된 트레이스로 동작 효과적으로 디버그
   ↓
4. 트레이스 → 체계적인 테스트 데이터셋 생성
   ↓
5. 데이터셋 + 평가자 생성 → 에이전트 정확도 검증
   ↓
6. 평가 + 사람 피드백 기반으로 에이전트 아키텍처 개선
   ↓
   반복 → 에이전트 스스로 진화
"에이전트 개선 루프는 점점 터미널 기반의 다른 에이전트에 의해 주도될 것"
LangSmith CLI는 그 흐름을 위한 기반 도구

설치 방법

# 현재 프로젝트 (로컬)
npx skills add langchain-ai/langsmith-skills --skill '*' --yes

# 전역 (모든 프로젝트)
npx skills add langchain-ai/langsmith-skills --skill '*' --yes --global

# Claude Code에 특정 연결
npx skills add langchain-ai/langsmith-skills --agent claude-code --skill '*' --yes --global
