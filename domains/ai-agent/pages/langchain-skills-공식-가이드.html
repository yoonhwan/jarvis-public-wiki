LangChain Skills — 공식 가이드

원문: https://blog.langchain.com/langchain-skills/
발행: 2026-03-04 | by LangChain Team

성능 향상 수치

테스트모델통과율
Claude Code (스킬 없음)Sonnet 4.625%
Claude Code (스킬 있음)Sonnet 4.695%

스킬이란?

전문 도메인에서 코딩 에이전트 성능을 향상시키기 위해 큐레이션된 지침, 스크립트, 리소스의 묶음.

Progressive Disclosure (점진적 공개) 방식으로 동적 로드:

  • 에이전트가 관련 태스크를 만날 때만 스킬 로드
  • 너무 많은 툴/정보 → 성능 하락 (기존 연구에서 검증됨)
  • 마크다운 파일 + 스크립트 → 포터블하고 공유 가능

11개 LangChain Skills 상세

카테고리 1: LangChain

클래식 툴 콜링 에이전트 루프 기초

  • create_agent() 사용법
  • middleware 패턴
  • tool patterns

카테고리 2: LangGraph

LangGraph 프리미티브 + 고급 기능

  • LangGraph primitives 작업 방법
  • Human In the Loop 네이티브 지원 활용
  • Durable Execution (지속 가능한 실행) 활용
  • 기타 고급 기능

카테고리 3: Deep Agents

오픈소스 Deep Agents 패키지

  • Deep Agents 패키지 활용
  • prebuilt middleware 사용
  • FileSystem 활용
