Perplexity Decider v1.3 — 판단·정보추출 특화 오픈소스 모델

Perplexity가 판단(분류·스코어링)과 정보 추출에 특화된 Decider v1.3(27B)와 Decider Flash v1.3(4B)을 Apache 2.0으로 공개했다. 새 기능 locate는 문서에서 원하는 정보를 찾아 원문 구간 + 문자 위치(offset) + 신뢰도까지 돌려준다. 자체 평가에서 기존 프로덕션 분류기 대비 +6.54%p 정확도.

locate — 원문 구간 추출 (새 기능)

분류 모델인데 생성 없이 원문을 그대로 잘라 온다는 점이 핵심. span head가 시작·끝 위치를 점수화하고, 필드별 임계값을 스스로 예측한다.

항목내용
반환값spans[] — start, end(exclusive), text, score
정합성state[start:end] == text 보장
질문 방식키 이름이 곧 라벨("person"), instructions로 자연어 지시 대체 가능
요청 제약텍스트 state 필수, 이미지 불가, 요청당 최대 128개 locate 질문
길이기본 max_length 32,768 토큰, 초과 시 LengthError
혼합같은 state에 locate·choice·score 질문을 함께 묶을 수 있음 (단, 타입별로 forward pass 분리 → 지연 증가)
학습`<\locate\>` 토큰 + span head + LoRA. 기존 백본·decision head는 동결. 어댑터는 병합하지 않고 locate 요청에서만 활성화 (병합 시 판단 성능 회귀)
response = decider.decide({
    "state": "...",
    "questions": {
        "urgent": {"type": "noul", "instructions": "Is the customer blocked right now?"},
        "error": {"type": "locate", "instructions": "Error codes"},
    },
})
for span in response["answers"]["error"]["spans"]:
    print(span["start"], span["end"], span["text"], span["score"])

질문 타입 (v1.3 스키마)

typecriteria반환
choice{옵션명: 설명 또는 null}, 1~255개choice, probabilities, confidence
noul (yes/no)선택적 {"true":…, "false":…}noul = P(true)
score2~255단계 설명 목록, 낮은 순score(기대 인덱스), probabilities, legend, confidence
locate미사용(키가 라벨)spans[]
  • 255개 상한은 readout head가 255행이라 생기는 구조적 한계.
  • 옵션 순서가 확률에 영향을 주지 않도록 학습됐고, 실측 흔들림률은 0.27%.
  • 같은 Decider 인스턴스의 decide()/logits() 호출은 내부 락으로 직렬화 — 병렬 추론은 인스턴스를 따로 만들어야 함.
  • 랭킹에는 확률 대신 noul 질문의 logit margin(true−false) 사용 권장 (확률은 포화되어 동점이 됨).

실무 메모 (우리 환경 기준)

  • 모델카드 요구사항은 Python 3.12+ / CUDA GPU(v1.3 약 49 GiB, Flash 약 8.5 GiB). MPS·MLX 경로는 문서화되어 있지 않음 — Apple Silicon에서 바로 돌리는 길은 아직 없음.
  • v1.2에는 pplx-decider-flash-gguf-v1.2(GGUF)가 있지만 v1.3 GGUF는 아직 없음. llama.cpp 계열로 붙이려면 변환 작업이 선행돼야 함.
  • 모델카드에 "The repository is private: authenticate with a Hugging Face token" 문구가 남아 있으나, HF API 조회 결과 gated=false·private=false로 실제로는 공개 상태(2026-11-15 확인). 문서 잔재로 보임.
  • 다운로드 수(HF 공개 2026-11-10 이후 5일 누적): v1.3 332, Flash 556 — 같은 시점 v1.2 계열은 각 6,169·7,578로 아직 v1.2 사용자가 더 많음.
