한 줄 요약

NVIDIA가 기업 데이터의 메타데이터에서 온톨로지(의미·관계 체계)를 자동 생성하고, AI 에이전트가 올바른 데이터를 골라 SQL을 쓰도록 돕는 Auto Ontology를 Apache-2.0 오픈소스로 공개했다.

본문 (Main Post)

NVIDIA가 온톨로지를 자동으로 구축하는 오픈소스 Auto Ontology를 공개했다.

  • 온톨로지는 데이터의 의미와 관계를 정리한 체계다.
  • 예: 회사에 매출을 뜻하는 항목이 여러 개 있으면, 각각의 정의와 관계를 구분해 AI가 잘못된 데이터를 쓰지 않도록 돕는다.
  • Auto Ontology는 데이터베이스를 분석해 이런 체계를 자동으로 만들고, AI가 질문에 맞는 데이터를 찾아 SQL을 작성하도록 지원한다.
  • Postgres, Snowflake 등을 지원하며 MCP를 통해 Claude Desktop이나 Cursor에서도 쓸 수 있다.

무엇인가

에이전트는 문서를 검색하고 DB를 조회할 수 있지만, "매출 지표가 틀리면 빨리 답해도 소용없다"는 신뢰성 문제가 병목이다. Auto Ontology는 기업 메타데이터에서 컨텍스트 계층(어디에 데이터가 있고, 무슨 뜻이며, 써도 되는지, 어떻게 쓰는지, 출처, 유사 항목)을 만들고 MCP, CLI, API로 어떤 에이전트 하네스에도 노출한다. 고객이 이미 가진 시맨틱 모델을 대체하지 않고 보완한다고 설명한다.

5가지 역할

단계하는 일
Discover메타데이터로 엔터프라이즈 온톨로지 생성, 기존 온톨로지·시맨틱 모델 연결, AI용 지식 그래프 구축
Ground지표·엔터티·관계의 비즈니스 의미를 에이전트에 제공, 시스템 간 불일치 정의 정리
Validate생성된 쿼리를 인증된 정의와 계보(lineage)로 검증, 답변마다 출처(provenance) 반환
ExposeMCP, CLI, API로 어떤 에이전트 하네스에도 컨텍스트 제공
Learn인증된 수정·사용 이력을 온톨로지에 되먹임

지원 데이터소스

Databricks, Postgres, Snowflake, DuckDB (README Prerequisites 기준).

설치·배포

  • 로컬: Docker Compose v2 → .env.example을 복사해 .env 작성 → docker compose up -d --build → UI는 http://localhost:3000`.
  • 쿠버네티스: Helm 차트, DEPLOYMENT.md 참조.
  • AUTHSECRET, APPURL은 필수. 없으면 Better Auth "default secret" 오류가 난다.

API·에이전트 연동

  • 인증: SSO 지원, 스크립트용 API 토큰(x-api-key 또는 Authorization: Bearer). 토큰은 소유자 권한으로 동작하고 SHA-256 해시만 저장된다.
  • 대화형 질의: POST /api/chat/completions (SSE 스트림, step/result/error 이벤트 후 [DONE]). conversation_id(UUID)를 주면 최근 5턴(최대 12,000자)을 반영해 "8월은?" 같은 질문을 독립 질문으로 재작성한다.
  • MCP 서버: mcp/ 디렉터리, 상세는 docs/mcp.md. Cursor, Claude Desktop에서 질의 가능.
  • 코딩 에이전트용 스킬: skills/에 nvidia-ontology-setup, nvidia-ontology-management, nvidia-ontology-query. 진입점은 AGENTS.md.
  • 벤치마크: BIRD 같은 text-to-SQL 평가는 별도 저장소 NVIDIA/ontology-sql-eval 참조.
