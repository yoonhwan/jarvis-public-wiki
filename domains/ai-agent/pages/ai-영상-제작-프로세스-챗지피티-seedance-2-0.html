본문 (Main Post)

AI 영상 만들 때 제가 쓰는 프로세스입니다.

챗지피티 (ChatGPT)

  1. 시나리오 업로드
  2. 모델 이미지, 배경 이미지 업로드
  3. 시나리오 중간 발췌 (15초 분량)
  4. JSON 프롬프트 변환
  5. 검수 및 컷 길이, 앵글 조정

Seedance 2.0

  1. 위의 모델 이미지, 배경 이미지 업로드
  2. 위의 JSON 복붙
  3. 프롬프트 내 참조 이미지 맞게 태그
  4. 720p 추출
  5. 오케이컷 나올 때까지 프롬프트 수정
  6. 프롬프트에 이상이 없다면 같은 프롬프트 재생성
  7. 오케이 컷 선별

아래는 업스케일링, 색보정 하기 전 원본입니다.

시나리오를 업로드하는 건, 챗지피티가 맥락을 이해해야 프롬프트 내에 분위기와 연기가 살아납니다.

프롬프트는 댓글에 달았습니다.

댓글 스레드 (Reply Thread — 작성자 추가 내용)

프롬프트: 인물 현실성 높이기

AI로 인물을 만들 때 현실성을 높여주는 프롬프트 한 줄

✨ 인물 얼굴을 자연광으로 자연스럽게 리라이팅해
  • ChatGPT를 통해 인물을 캐릭터 시트 형태로 생성
  • 이후 생성된 사진을 리라이팅하라 해서 현실감을 높임
  • 보통 얼굴이 스튜디오 조명처럼 과다하게 밝게 생성되는데, 그럼 AI 티가 많이 남
  • 현실에선 그렇게 얼굴이 밝고 하얗지 않음
  • 첨부할 캐릭터 시트 자체가 자연스러움이 있어야 이후 영상도 현실감이 생김 (모든 영상에 참조로 들어가기 때문)
  • 참조로 들어간 이미지는 단순 인물 일관성만 따라가는 게 아니라, 이미지 내의 질감·조명 등 모든 정보를 참조함

핵심 요약

단계도구역할
기획ChatGPT시나리오 맥락 이해 → JSON 프롬프트 변환
인물ChatGPT캐릭터 시트 생성 + 자연광 리라이팅으로 현실감 부여
