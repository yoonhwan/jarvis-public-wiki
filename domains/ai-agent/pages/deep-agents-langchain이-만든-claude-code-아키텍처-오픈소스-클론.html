Deep Agents — LangChain이 만든 Claude Code 아키텍처 오픈소스 클론

원본: https://www.threads.com/@feelfreeai/post/DV5qRthEUCS
GitHub: https://github.com/langchain-ai/deepagents

요약

LangChain이 Claude Code의 아키텍처를 MIT 라이선스로 완전 오픈소스화한 프로젝트. 'Deep Agents'라는 이름으로, LangGraph 기반의 프로덕션 레벨 에이전트 하니스(harness)를 제공한다. Claude Code에서 영감을 받아 "무엇이 범용 에이전트를 만드는가"를 분석하고 더 범용적으로 확장한 것.

핵심 포인트

기본 탑재 기능 (Batteries Included)

  • Planning: write_todos — 무턱대고 툴 실행이 아니라, TO-DO 리스트부터 짜고 움직임
  • Filesystem: readfile, writefile, edit_file, ls, glob, grep — 파일 시스템 직접 R/W
  • Shell: execute — 명령 실행 (샌드박싱 지원)
  • Sub-agents: task — 복잡한 작업을 서브 에이전트에게 분리 위임 (격리된 컨텍스트)
  • Context Management: 대화가 길어지면 자동 요약, 큰 출력은 파일로 저장
  • Human-in-the-loop: 중요 구간에서 사람 승인 필수 게이트

아키텍처 특성

  • 100% 오픈소스 (MIT 라이선스)
  • Provider 무관 — 도구 호출 지원하는 어떤 LLM이든 사용 가능 (프론티어 + 오픈 모델)
  • LangGraph 기반 — 스트리밍, 체크포인팅, 퍼시스턴스 프로덕션 런타임
  • MCP 지원 — langchain-mcp-adapters를 통한 MCP 도구 연결
  • LangSmith 통합 — 개발/디버깅/배포 트레이싱

보안 모델

  • "Trust the LLM" 모델 — 에이전트가 도구가 허용하는 모든 것을 할 수 있음
  • 경계는 모델 자기 검열이 아닌 도구/샌드박스 레벨에서 강제

설치 & 사용

# Python 패키지
pip install deepagents
# 또는
uv add deepagents

# CLI 설치
curl -LsSf https://raw.githubusercontent.com/langchain-ai/deepagents/main/libs/cli/scripts/install.sh | bash
from deepagents import create_deep_agent

# 기본 에이전트 (즉시 사용 가능)
agent = create_deep_agent()
result = agent.invoke({
    "messages": [{"role": "user", "content": "Research LangGraph and write a summary"}]
})

# 커스텀 에이전트
from langchain.chat_models import init_chat_model

agent = create_deep_agent(
    model=init_chat_model("openai:gpt-4o"),
    tools=[my_custom_tool],
    system_prompt="You are a research assistant.",
)

Claude Code와의 관계

프로젝트 공식 설명에서 명시:

"This project was primarily inspired by Claude Code, and initially was largely an attempt to see what made Claude Code general purpose, and make it even more so."

Claude Code의 핵심 설계(Planning → Filesystem → Sub-agents → Context Management)를 분석하고 LangGraph로 재구현한 것.

yoonhwan 오빠 관련성

  • BaseAgent 프로젝트와 아키텍처 비교 대상 — LangGraph 기반 에이전트 하니스
  • Gas Town 21 Crew의 서브 에이전트 패턴과 유사한 task 도구
  • OpenClaw의 sub-agent 시스템과 컨셉 유사 (격리된 컨텍스트 위임)
  • MIT 라이선스라 실무 참고/포크 자유로움
