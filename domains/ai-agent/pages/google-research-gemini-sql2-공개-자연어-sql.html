Google Research, Gemini-SQL2 공개 (자연어 → SQL)

Google Research가 자연어를 SQL로 변환하는 Gemini-SQL2를 공개했다. Gemini 3.1 Pro 기반으로 개발되었으며, 텍스트로 질문하면 실제 실행 가능한 SQL 쿼리를 생성하는 것이 특징.

주요 포인트

  • Gemini 3.1 Pro 기반 — Google의 최신 LLM을 SQL 생성에 특화
  • BIRD 벤치마크 최고 성능 — Single Model 카테고리에서 80.04% Execution Accuracy 기록
  • 복잡한 데이터 구조 환경에서도 높은 정확도 유지
  • 향후 Google 데이터 분석 서비스(BigQuery, Looker 등)에 활용될 가능성
