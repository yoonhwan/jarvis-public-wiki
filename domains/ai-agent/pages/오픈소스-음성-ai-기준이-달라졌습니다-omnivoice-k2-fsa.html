오픈소스 음성 AI, 기준이 달라졌습니다.

목소리 샘플 하나로 600개 언어를 복제하는 TTS, k2-fsa가 공개 5개월 만에 스타 1만을 넘겼습니다.

핵심만 뜯어봤습니다.

댓글 스레드 (Reply Thread — 작성자 추가 내용)

1/ 600개 이상 언어, 제로샷 음성 클로닝

짧은 음성 샘플 하나만 있으면 목표 화자 목소리를 복제해서 다른 언어로 말하게 만듭니다.

유료 클로닝 서비스에 매달 돈 쓰던 사람이라면, 셀프호스팅으로 갈아탈 이유가 생겼어요.

2/ 추론 속도, 실시간의 40배

RTF(Real-Time Factor) 최저 0.025, 숫자가 작을수록 빠르다는 뜻입니다.

대량 배치 처리든 실시간급 응답이든, 서비스에 바로 붙일 수 있는 속도라 적용 폭이 넓어지네요.

3/ 클로닝 없이 목소리를 새로 설계

성별, 나이, 피치, 방언, 속삭임까지 속성만 지정하면 새 목소리를 만들어냅니다. [laughter] 같은 비언어 심볼과 발음 교정도 지원해요.

성우 섭외 없이 원하는 목소리를 그때그때 뽑아낼 수 있다는 얘기예요.

4/ 설치 장벽이 낮습니다

pip install "omnivoice[tn]" 한 줄로 설치 끝, Python API·CLI·Gradio 데모 중 골라서 바로 실행됩니다.

따로 서버 세팅 안 해도, 오늘 로컬에서 바로 돌려볼 수 있잖아요.
