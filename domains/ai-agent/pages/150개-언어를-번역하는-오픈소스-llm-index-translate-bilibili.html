150개 언어를 번역하는 오픈소스 LLM, Index-Translate (Bilibili)

본문 (Main Post, @aiwire_kr)

150개 언어를 번역하는 오픈소스 LLM이 공개됐어요.

Bilibili의 IndexTeam이 Qwen3.5 기반 번역 LLM 패밀리를 공개했습니다. 2B·9B·35B 모델이 HuggingFace·ModelScope에 있고, 용어·서식·내용 보존을 지시할 수 있어요.

음성→자막·음성→음성 더빙(Index-Echo), 음절 수 맞춤 번역(Index-Homura), 장문 문서 번역(Index-NativeLong)으로 확장되며, llama.cpp·vLLM 양자화 빌드와 OpenAI 호환 무료 API, 번역 벤치마크까지 함께 제공합니다.

GitHub: https://github.com/bilibili/Index-Translate

핵심 요약 (README 기준)

  • 베이스 모델: Qwen3.5
  • 지원 언어: 텍스트 번역 150개 언어 (음성/장문 패키지는 언어 범위 별도)
  • 라이선스: Apache 2.0
  • 공개 시점: 2026-09-30 (2B/9B/35B-A3B preview 가중치) → 2026-10-03 양자화 빌드 → 2026-10-04 무료 API + 벤치마크 공개

양자화: 전 모델 GGUF(llama.cpp 로컬), FP8(vLLM W8A8), FP4(vLLM NVFP4, Blackwell용) 공식 제공.

0. 셀프호스팅 (로컬/자체 서버 운영 — yoonhwan 환경 1차 경로)

git clone https://github.com/bilibili/Index-Translate.git
cd Index-Translate
pip install -U vllm
pip install -r inference/llm/requirements.txt
vllm serve IndexTeam/Index-Translate-2B --host 127.0.0.1 --port 8000 --max-model-len 4096

다른 터미널에서:

python inference/llm/translate.py \
  "你好，世界。今天天气不错，我们去公园散步吧。" \
  --target en --model IndexTeam/Index-Translate-2B

→ Hello, world. The weather is nice today. Let's go for a walk in the park.

  • 텍스트 클라이언트 기본값: http://127.0.0.1:8000/v1, API key EMPTY. --base-url/--api-key/OPENAIBASEURL/OPENAIAPIKEY`로 override 가능.
  • GGUF 빌드는 llama.cpp로 로컬(CPU/Apple Silicon 포함) 서빙 가능 — Mac MLX 환경에선 GGUF 경로가 가장 적합.
  • serve_vllm.sh 기준 context: 2B/9B 32768 (35B는 별도 preset 없음).

강제 조건(Instruction Following) 예시 — 셀프호스팅 공통

# 용어집 강제
python inference/llm/translate.py "王平仲采用了更加昂贵的碳纤维材料。碳纤维的好处就是它抗裂缝。" \
  --target en -g "碳纤维:carbon fiber, 抗裂缝:crack resistance"

# JSON 포맷 보존
python inference/llm/translate.py \
  '{"user_id": 1024, "event": "purchase", "message": "您的订单已支付完成。"}' \
  --target en -H "保留源文中的 JSON 格式标记不变"

# 음절수 맞춤 (Index-Homura)
python inference/llm/syllable_translate.py "我们今天去看电影吧" --syllables 7 --target en --glossary "电影:cinema"

1. (참고/보조) 무료 공개 API — GPU 불필요

Bilibili가 공개 운영하는 무료 엔드포인트, OpenAI 호환. (yoonhwan 환경은 셀프호스팅이 1차지만, 빠른 테스트용으로 참고)

# zero-dependency 커맨드라인 번역
python inference/llm/call_api.py "你好，世界。" --target en

# OpenAI 호환 Chat Completions
curl https://index-translate.bilibili.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "Index-Translate-35B-A3B", "messages": [{"role":"user","content":"번역해줘..."}]}'

브라우저 확장(이머시브 트랜스레이트 등)에서 쓰려면 CORS/WAF 때문에 로컬 프록시 필요: python inference/llm/call_api.py --serve → http://127.0.0.1:8080/v1`.
