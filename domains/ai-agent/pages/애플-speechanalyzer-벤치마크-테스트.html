애플 SpeechAnalyzer 벤치마크 테스트

Jinho Jung (@jvisualschool) on Threads

본문 (Main Post)

SpeechAnalyzer는 macOS 26 / iOS 26부터 애플이 새로 넣은 음성 인식 엔진입니다. 로컬에서 동작합니다.

  • 강의, 회의, 팟캐스트 같은 몇십 분짜리 녹음도 한 번에 처리하도록 새로 설계됨
  • M1 이상의 애플 실리콘, macOS 26 (Tahoe) 이상에서 동작

빌드 방식

  • SpeechAnalyzer를 이용하려면 바이너리 컴파일을 위해 Xcode가 필요
  • 작성자는 무거운 Xcode 대신 swift CLI로 빌드
  • 바이너리 실행을 위한 간단한 웹 UI를 로컬에서 제작
  • 대략 5분짜리 파일을 만들어 테스트 → "너무너무 빠릅니다"

테스트 장비

Apple M3 Pro, 12코어(6P+6E), 36GB, macOS 26.5.2

블로그 코드 샘플 (따라서 만들기 — 5단계)

블로그 원문: Xcode 없이, 터미널만으로 Apple의 새 음성인식 API를 켜봤다

1. Command Line Tools 확인·설치

$ xcode-select -p
/Library/Developer/CommandLineTools

# 없다면 설치
$ xcode-select --install

2. 작업 폴더 만들기

$ mkdir -p ~/speechanalyzer-test && cd ~/speechanalyzer-test

3. Swift 코드 파일 만들기 (main.swift)

import Speech
import AVFoundation
import Foundation

@main
struct SpeechAnalyzerTest {
    static func main() async {
        guard CommandLine.arguments.count > 1 else {
            print("사용법: ./SpeechAnalyzerTest <오디오파일 경로> [locale, 기본값 ko-KR]")
            exit(1)
        }
        let path = CommandLine.arguments[1]
        let localeID = CommandLine.arguments.count > 2 ? CommandLine.arguments[2] : "ko-KR"
        let url = URL(fileURLWithPath: path)
        let locale = Locale(identifier: localeID)

        do {
            let transcriber = SpeechTranscriber(locale: locale, preset: .transcription)

            if let request = try await AssetInventory.assetInstallationRequest(supporting: [transcriber]) {
                print("온디바이스 언어 모델 다운로드 중...")
                try await request.downloadAndInstall()
                print("다운로드 완료.")
            }

            let audioFile = try AVAudioFile(forReading: url)
            let analyzer = SpeechAnalyzer(modules: [transcriber])

            let resultsTask = Task {
                for try await result in transcriber.results {
                    print("[결과] \(result.text)")
                }
            }

            try await analyzer.start(inputAudioFile: audioFile, finishAfterFile: true)
            try await analyzer.finalizeAndFinishThroughEndOfInput()
            await resultsTask.value

            print("완료.")
        } catch {
            print("에러 발생: \(error)")
            exit(1)
        }
    }
}

4. 컴파일하기 (swiftc, Xcode 불필요)

$ SDK=$(xcrun --sdk macosx --show-sdk-path)
$ swiftc -target arm64-apple-macos26 -sdk "$SDK" -parse-as-library \
    main.swift -o SpeechAnalyzerTest \
    -framework Speech -framework AVFoundation

5. 실제 오디오로 실행하기

$ ./SpeechAnalyzerTest ~/Desktop/내오디오.mp3 ko-KR
온디바이스 언어 모델 다운로드 중...
다운로드 완료.
[결과] 여기에 인식된 텍스트가 그대로 출력됩니다
완료.

핵심 포인트

  • SpeechTranscriber(locale:preset:) — 온디바이스 트랜스크라이버 생성
  • AssetInventory.assetInstallationRequest — 언어 모델을 온디바이스로 다운로드/설치
  • SpeechAnalyzer(modules:) — 트랜스크라이버 모듈을 묶어 분석기 구성
  • analyzer.start(inputAudioFile:finishAfterFile:) — 오디오 파일 스트리밍 처리
  • Speech + AVFoundation 프레임워크만 링크하면 Xcode 없이 CLI 빌드 가능 (target: arm64-apple-macos26)
