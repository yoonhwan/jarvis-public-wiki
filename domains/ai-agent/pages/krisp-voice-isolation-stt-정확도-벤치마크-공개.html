Krisp Voice Isolation — STT 정확도 벤치마크 공개

음성 AI 에이전트가 주변 사람 말소리까지 섞어 알아듣는 문제(화자 중첩)를, STT 모델을 바꾸지 않고 전처리 단계의 음성 분리(Voice Isolation)만으로 얼마나 개선할 수 있는지 Krisp이 공개 데이터셋 + HuggingFace Space로 검증한 벤치마크.

본문 (Main Post)

음성 AI 에이전트가 주변 사람의 말까지 섞어 알아듣는 문제를 해결하기 위해, Krisp에서 STT 모델 변경 없이 음성 분리(Voice Isolation) 적용만으로 평균 단어 오류율(WER)을 69.57%에서 2.97%까지 낮춘 벤치마크를 공개했습니다.
업무 환경과 콜센터 등 실제 녹음 데이터 265개를 활용해 화자 중첩 구간에서의 배경 음성 억제 효과를 검증했으며, 주변 소음이 적은 일반 통화에서는 오류율이 3.5%에서 3.9%로 소폭 오르는 한계까지 과장 없이 투명하게 비교했다고 합니다.

출처 표기(작성자 댓글): huggingface.co/spaces/Krisp-AI/VoiceIsolation-Benchmark

댓글 스레드 (작성자 feelfree_ai, Related thread — 같은 주제 추가 포스트)

Threads 상에서 "Related threads"로 묶여 있으나 실제로는 같은 작성자(feelfree_ai)가 이틀 전(10/04) 올린 선행 포스트로, 같은 벤치마크를 다른 수치로 다시 소개:

아무리 강력한 LLM을 연동해도 주변 사람의 목소리가 텍스트로 섞여 들어가는 순간, 음성 에이전트는 사용자의 본래 의도를 복구할 수 없습니다.
Krisp 벤치마크 결과를 보면 배경 소음보다 다른 사람의 말이 겹치는 환경에서 음성 분리(Voice Isolation)를 거쳤을 때 오류율이 23.3%에서 6.2%까지 극적으로 떨어집니다.

⚠️ 수치 불일치 — 원문 캡션 vs 공식 벤치마크 페이지

같은 Threads 계정이 올린 두 포스트가 서로 다른 숫자를 인용하고 있고, 공식 Krisp 벤치마크 페이지(krisp.ai/benchmarks/voice-isolation-benchmark/)의 전체 집계 수치와도 다릅니다. 원문을 과장 없이 전달하기 위해 세 출처를 모두 표로 남깁니다.

판단: 공식 페이지 기준으로는 전체 평균이 23.2% → 6.2%가 맞는 숫자입니다. 원문이 인용한 "69.57% → 2.97%"는 공식 benchmark 페이지 텍스트 어디에도 그대로 나오지 않아 — 특정 STT 엔진(11개 구성 중 하나) 또는 특정 시나리오(업무/콜센터 등)의 개별 수치를 평균인 것처럼 잘못 인용했을 가능성이 있습니다. HuggingFace Space의 인터랙티브 결과 테이블(JS 렌더링이라 정적 추출 불가)을 직접 열어 확인하지 않는 한 어느 조합의 숫자인지는 확정할 수 없습니다.

측정 방법론

  • WER 계산: jiwer 4.0.0, word-level alignment, corpus-level pooling
  • 정규화 3단계: ① 정규식으로 우편번호/문자-숫자 토큰(NG-228 등)/4자리 숫자/전화번호 패턴 분리 → ② NVIDIA NeMo WFST로 숫자·통화·서수·시간 스펠아웃 → ③ jiwer로 소문자화, 축약형 전개, 구두점 제거, 필러워드(um/uh) 제거 후 단어 단위 정렬
  • 체감 음질: DNSMOS-C(NISQA 학습) — 주 화자가 말하는 구간에만 적용(무음 구간 품질은 측정 안 함), 4개 모델 전부 모든 시나리오에서 MOS 상승

캐비엇 (공식 페이지가 직접 명시)

전화통화 시나리오는 이미 narrowband이고 경쟁 음성이 거의 없어 제거할 게 적음. 대부분 모델이 raw 대비 ±0.5%p 이내에 머물고, 파일 단위로는 중립이거나 개선되는 경우가 대부분이지만 음질이 나쁘거나 매우 시끄러운 일부 파일에서는 주 화자 분리가 어려워 오히려 소폭 악화되는 경우도 있음(예외 사례로 공개됨, 숨기지 않음).
