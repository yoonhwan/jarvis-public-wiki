본문 (Main Post)

근처 다이소에 수납박스가 있는지 AI에게 물어볼 수 있는 MCP가 있다고 하네요.
DAISO MCP는 다이소, 올리브영, GS25, CU, 세븐일레븐, 이마트24의 상품과 재고에 CGV·메가박스·롯데시네마 시간표와 잔여 좌석, 주유소 가격까지 조회한대요. 계정도 API 키도 필요 없는 공개 원격 서버라고 합니다.
Claude Code에선 claude mcp add daiso-mcp https://mcp.aka.page --transport http 한 줄이면 되고, MIT예요. 재고는 조회 뒤 달라질 수 있다니 참고용으로 보는 게 좋겠고요.
개발 도구는 아니지만 한국 생활 정보가 바로 붙는다는 점이 재밌어 보여요.
  • 작성 시점: 수집 기준 약 7시간 전 게시
  • 댓글 스레드: 작성자 추가 답글 없음, 다른 사용자 댓글 없음 (로그아웃 상태 read 기준)

사용법

1. 원격 MCP 연결

claude mcp add daiso-mcp https://mcp.aka.page --transport http
  • 그 외 AI 앱: "원격 MCP 서버 추가" 화면에서 서버 URL 입력, 전송 방식은 HTTP / Streamable HTTP 선택
  • 요청 예: 다이소 MCP로 수납박스 검색해줘

2. CLI

npx daiso products 수납박스 --json
  • 에이전트용 Skill: clawhub install daiso-cli (원격 MCP만 쓰면 CLI·Skill 설치 불필요)

3. 웹 조회 (MCP 연결 불가 환경)

  • /browse/ 경로의 자동 HTML GET: https://mcp.aka.page/browse/quick
  • REST 사용법: https://mcp.aka.page/prompt

질문 예시 (README)

  • 다이소 수납박스 찾아줘
  • 강남역 근처 GS25 오감자 재고 알려줘
  • 주변에서 휘발유가 가장 저렴한 주유소 찾아줘
  • 오늘 강남 CGV 시간표 알려줘
  • 콜라 어디가 싼지 비교해줘 (판매처별 가격 후보 비교)

주의사항

  • 재고와 잔여 좌석은 조회 후 달라질 수 있음. 미확인 결과는 품절·재고 0과 구분됨.
  • 느린 다이소 조회는 pending(접수 상태)으로 올 수 있음. 새 결과 확인 링크를 최대 3번 선택하고, 계속 pending이면 미확인으로 처리.
  • 공개 서버라서 요청이 제3자 서버(Cloudflare Workers)를 거침. 위치·검색어가 전달되는 점은 [확인 필요: 서버 쪽 로그 정책은 README에 명시 없음].
