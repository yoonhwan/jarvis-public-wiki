Qwen-Audio-3.0-TTS — 알리바바 통이랩 음성 모델

작성자: CHOI (@choi.openai) on Threads

본문 (Main Post)

알리바바 통이랩이 Qwen-Audio-3.0-TTS를 내놨습니다.

  • 실시간용 Flash와 고품질용 Plus로 나뉨
  • 16개 언어에 자연어로 톤을 지시하면 웃음이나 숨소리 같은 비언어 표현까지 태그로 넣음
  • 독립 평가 Artificial Analysis TTS 리더보드에서 1위

공개 방식의 특징

  • 이번 최상위 버전은 오픈 웨이트가 아닌 알리바바 클라우드 API로만 열림
  • 같은 알리바바가 며칠 전 플래그십 LLM Qwen3.8은 오픈웨이트로 예고했는데, 정작 1위 음성 모델은 유료 API에 묶어둠
  • 음성은 딥페이크 위험이 크고 실시간 API로 돈이 되는 영역이라, 제일 잘하는 모델은 계속 API 안에 남을 것으로 전망
