Fable 오케스트레이션 — 토큰 아끼려면 "말"이 아니라 "강제 게이트"로 막아라

@joelww Threads 스레드 (댓글 스레드 포함 ✅)

핵심 요약

Fable(메인 오케스트레이터) 오케스트레이션의 핵심은 "Fable이 똑똑하게 일하게 하는 것"이 아니라 "Fable이 비싼 일을 직접 못 하게 물리적으로 막는 것". CLAUDE.md에 "지휘만 하고 구현은 위임한다"고 적는 건 권고일 뿐이라 모델이 언제든 우회 가능. PreToolUse 훅으로 강제 게이트를 만들어야 실제로 차단된다.

4개 레이어가 함께 있어야 한다

파일역할
CLAUDE.md선언 (declaration)
/agents역할 배정 (role assignment)
rules/orchestration.md운영 기준 (operating criteria)
hooks/orchestration-gate.sh강제 장치 (enforcement)

본문 (Main Post + 작성자 스레드)

1. 문제 제기

대부분 CLAUDE.md에 "Fable은 지휘만 하고 실제 구현은 하위 모델에게 위임한다"고 적고 끝낸다. 방향은 맞지만 이건 권고일 뿐 — 모델이 마음먹으면 직접 코드를 고칠 수 있다. 토큰을 아끼려면 말로 설득하지 말고 물리적으로 못 하게 막아야 한다.

2. 왜 중요한가 (비용)

Fable 5는 비싼 모델. 보일러플레이트/테스트/포매팅 같은 실행 작업을 시키면 비싼 토큰이 싼 일에 녹는다. Fable은 판단만 해야 한다:

  • 계획
  • 작업 분배
  • 중요한 결정
  • 결과 종합

실제 손발은 하위 모델이 맡는다.

3. CLAUDE.md + /agents 설정 (기본)

## 오케스트레이션
Fable은 판단 중심으로 움직인다.

계획, 분배, 종합은 Fable이 맡는다.
실제 실행은 서브에이전트에게 위임한다.

무거운 추론은 deep-reasoner(Opus),
일반 구현은 default-worker(Sonnet),
잡무는 task-worker(Haiku)가 맡는다.

새 관점이 필요한 문제는 codex exec로 병렬 검토한다.

하지만 여기서 끝내면 약하다.

4. rules/orchestration.md (진짜 핵심)

"언제 Fable이 직접 처리하고, 언제 위임할지" 기준을 명확히 적는다.

Fable 직접 처리:

  • 1~2개 파일의 작은 수정
  • 오타 수정
  • 설정 변경
  • 문서 수정
  • 단순 질문·조회

위임 대상:

  • 새 기능 구현
  • 3개 이상 파일 변경
  • 50줄 이상 변경 예상
  • 테스트 코드 작성
  • 리팩토링

작은 작업까지 위임하면 오히려 왕복 비용이 더 크다.

5. 강제 게이트 (가장 중요)

말로만 "Fable은 코드 수정하지 마"는 부족. PreToolUse 훅을 둔다:

  • 메인 에이전트가 코드 파일을 한 턴에 2개까지만 수정 허용
  • 3개째부터 차단
  • 차단되면 모델에게 위임 지시가 전달됨

즉, Fable이 직접 구현으로 폭주하는 걸 물리적으로 막는 구조.

6. 우회 경로도 막아라

훅은 완벽하지 않다. Bash에서 sed, echo, 리다이렉트로 파일을 고치면 게이트를 우회할 수 있다. 그래서 규칙에 이것도 적어야 한다:

메인 에이전트는 Bash로 코드 파일을 수정하지 않는다.
코드 수정이 필요하면 반드시 서브에이전트에게 위임한다.

오케스트레이션은 "좋은 말"이 아니라 우회 경로까지 줄이는 운영 규칙이어야 한다.

7. 정리 (역할 분담)

  • Fable — 판단
  • Opus — 깊게 생각
  • Codex — 다른 관점으로 검토
  • Sonnet — 구현
  • Haiku — 잡무
  • 훅 — 이 구조가 무너지지 않게 막는 안전장치

8. 결론

CLAUDE.md는 선언, /agents는 역할 배정, rules/orchestration.md는 운영 기준, hooks/orchestration-gate.sh는 강제 장치. 이 4개가 같이 있어야 한다.
그냥 "Fable은 지휘자다"라고 쓰는 건 약하다. 진짜 세팅은 Fable이 직접 코딩하고 싶어도 못 하게 만드는 구조.

💡 Claude에게 시키는 프롬프트 (Text 5)

CLAUDE.md 권고가 아니라 하네스가 물리적으로 차단하는 강제 게이트를 만들어라.
Fable이 코드 수정을 직접 많이 하지 못하게 PreToolUse 훅을 구성하고,
실환경에서 실제로 차단되는지 증명까지 마친 뒤 결과를 보고하라.

→ "규칙을 적어라"가 아니라 "규칙을 어겼을 때 실제로 막히게 만들어라".
