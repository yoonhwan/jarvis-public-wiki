Bilibili, 150개 언어 텍스트·음성 번역 모델 Index-Translate 5종 공개

Threads에서 PyTorchKR(@pytorch.kr) 계정이 공유한 글. 원문은 PyTorchKR 포럼(discuss.pytorch.kr)의 기술 리뷰 아티클이며, Threads 포스트 자체는 캡션 없이 외부 링크 공유(link-preview repost) 형태였음. OG meta에 전체 요약 일부가 포함되어 있었고, 전체 본문은 원문 Discourse 포스트(.json API)에서 확보.

한눈에 보기

  • 공개: Bilibili 산하 Index 팀, 2026-09-30
  • 베이스 모델: Qwen3.5
  • 라이선스: Apache 2.0 (코드+가중치 전체, 상업적 사용 가능)
  • 공개처: Hugging Face, ModelScope + 27쪽 기술 리포트 + 온라인 데모
  • 지원 언어: 150개 언어 (22개 핵심 언어 + 128개 추가/변종), 한국어 포함

핵심 설계: 왜 모델을 쪼갰나

  • 번역 모델이라고 "원문+목표언어 → 번역문"의 단순 함수가 아니라, 실제로는 게임 공지 JSON(키/해시태그 보존), 커뮤니티 은어, 더빙 시간 제약, 장문 인물명 일관성 등 용도별로 요구사항이 전혀 다름.
  • 공유 다국어 기반(Shared Multilingual Foundation) 위에서 일반번역/지시따르기/밈번역 3개 전문가를 파라미터 보간(Model Soups, 0.8:0.1:0.1) 으로 병합 → 약해진 부분은 MOPD(Multi-Teacher On-Policy Distillation) 로 보강.
  • 음절 제어처럼 병합 과정에서 생존율이 낮은 능력(병합 모델 SandGlass 적중률 0.1544 vs 전용모델 0.5439)은 Index-Homura로 완전히 분리.

학습 파이프라인 (텍스트 모델)

  1. 중간 학습(Mid-Training): Qwen3.5 베이스 + 다국어 중간학습. WSD 스케줄, 시퀀스 4096, 글로벌배치 4096, 총 1만 스텝(167.77B 토큰). Constant 단계(일반:병렬:단일언어=1:1:1, 7000스텝)→ Decay 단계(일반:pivot-20:pivot-148=1:4:2, 3000스텝)
  2. 전문가 SFT→RL: 일반번역/지시따르기/밈번역 3개 전문가를 각각 SFT 후 GRPO(일반/지시) 또는 LLM judge 보상(밈)으로 강화학습
  3. 병합: Model Soups 파라미터 보간 + MOPD 증류

언어 범위 확대 효과: 2B 모델 감쇠 단계 데이터를 20여개→100여개 언어로 넓히자 핵심언어 점수는 거의 유지(0.8231→0.8219)되면서 비핵심 61개 언어 평균이 0.5605→0.6570으로 상승, 오프타깃(엉뚱한 언어로 답하는) 비율 1.94%→0.89%로 감소.

읽을 때 주의할 점 (원문이 직접 지적):

  • WMT26은 GPT-5.6-Sol이 채점자이면서 동시에 비교 대상 1위 — 자기 선호 가능성 배제 불가. 참조기반 COMET 계열에서는 Index-Translate가 대등/우세하므로 같이 봐야 함.
  • 홈페이지 대표 표는 DeepSeek-V4.1-Flash와 WMT26을 생략해 35B-A3B가 저자원/밈 번역도 1위처럼 보이지만, 리포트 전체 표 기준으로는 두 항목 모두 2위.
  • 번역 특화 대가: Index-Translate-9B는 Qwen3.5-9B 대비 일반능력 벤치마크 대폭 하락 (C-Eval 86.6→69.6, GPQA-Diamond 75.8→36.3, MMMLU 75.9→66.6). 번역 전용으로 봐야 함.

Index-Echo (음성 번역)

  • S2TT: Qwen3-Omni의 AuT 오디오 인코더 + Index-Translate 디코더, 엔드투엔드 학습. 문장 단위 타임스탬프 기본 포함.
  • S2ST: ASR→번역→TTS 캐스케이드 대신, Hidden2CV 매퍼(~30M 파라미터)로 번역모델의 마지막 은닉 상태를 CosyVoice3 의미 계층에 직접 정렬. 증류 → DiffRO(Differentiable Reward Optimization) 2단계 학습.
  • 평가(7방향·140개 영상구간): Index-Echo-9B 번역품질(MT judge) 0.857 — Gemini-3.1-Pro(0.849)보다 높지만 Qwen3.8-Omni-Flash(0.887)보다 낮음. 원문 인식 오류·타임스탬프 오차는 2B/9B가 가장 낮음.
  • S2ST 엔드투엔드 vs 캐스케이드: 12개 조합 중 8개에서 엔드투엔드가 내용 오류율 더 낮음. 화자 유사도는 둘 다 ~0.72로 동등.

Index-Homura (음절 제어 더빙 번역)

  • SandGlass 벤치마크(자막 300문장 × 4언어 × 3길이 = 3,600 사례/모델)
  • Index-Homura-9B: 목표 음절 수 10% 이내 적중률 81.92% (GPT-5.6-Sol low 47.64%, DeepSeek-V4-Flash 16.36%, Hy-MT2-7B 18.86%)
  • 단, 번역 품질은 역전: DeepSeek-V4-Flash(0.8742) > GPT-5.6-Sol(0.8715) > Hy-MT2-7B(0.8560) > Index-Homura-9B(0.7863)
  • SFT→RL 전환 시 적중률 45.75%→81.92% 상승, 품질 0.8581→0.7863 하락 — 길이 제어와 품질은 트레이드오프 관계

Index-NativeLong (장문 번역)

  • 청크 분할 없이 문서 전체를 한 번에 번역 (vs 기존 LLM 번역의 chunk+glossary 방식)
  • 2B: 128K 시퀀스 감쇠 중간학습 모델 기반 / 9B: 통합 텍스트모델 기반, 중국어 기준 4K~64K 토큰 양방향 문서로 SFT
  • 평가: SEGALE로 블록 정렬 후 COMET 채점 (짝 안 맞으면 0점 — 번역 중단 시 점수 급락)
  • 길이가 늘어날수록 격차 확대: Hy-MT2-7B는 GuoFeng(중→영) 4K에서 0.7334였다가 64K에서 0.0001로 붕괴(짧은 조각만 번역하고 멈추는 현상). Index-NativeLong-9B는 64K에서도 0.7382 유지.
  • 인물명 일관성 사례: 王妃(Wang Fei)를 네이티브 9B는 32K 토큰 전체에서 일관되게 "Wang Fei"로 유지. 같은 9B를 청크 번역 파이프라인(TranslateBooksWithLLMs)에 넣으면 "Instructor Wangfei", "the Dean", "The Queen Consort"로 흔들림.

실행 방법 (vLLM)

git clone https://github.com/bilibili/Index-Translate.git
cd Index-Translate
pip install -U vllm
pip install -r inference/llm/requirements.txt
vllm serve IndexTeam/Index-Translate-2B --host 127.0.0.1 --port 8000 --max-model-len 4096
python inference/llm/translate.py \
  "你好，世界。今天天气不错，我们去公园散步吧。" \
  --target en --model IndexTeam/Index-Translate-2B
  • 텍스트 번역: temperature=0 그리디 디코딩, enable_thinking=False 기본
  • Index-Homura: syllable_translate.py --syllables <목표음절수>
  • Index-NativeLong: doc_translate.py (전체 문서 입력)
  • 서빙 컨텍스트: 텍스트 모델 32K / NativeLong 2B 262,144 토큰 / NativeLong 9B 229,376 토큰
  • GPU 메모리(bf16, KV캐시 별도): 2B ~8GB, 9B ~24GB. Index-Echo-S2ST는 별도 패키지(2B ~13GB/12GB VRAM, 9B ~26GB/24GB+ VRAM), 30초 이하 짧은 발화 단위
  • vLLM 0.29에서 테스트됨, SGLang 서빙도 가능
  • 부가 도구: 로컬 모델 기반 웹페이지 번역 브라우저 확장, 음성분리~더빙정렬 영상 더빙 파이프라인

평가 수치 해석 시 주의점 (원문 직접 언급)

  1. 자체 벤치마크 비중: instTrans, MEME, SandGlass, NativeLongBench, S2TT/S2ST 테스트셋 모두 Index 팀 자체 제작, 아직 비공개 (일부는 공개 예정)
  2. LLM 판정자 의존: 지시따르기·WMT26은 GPT-5.6-Sol, 밈·SandGlass 품질은 Gemini 2.5 Flash, 음성번역 품질은 Gemini 3.1 Pro가 채점. 학습 보상에도 Gemini 계열이 쓰여 판정자-보상모델 취향이 겹칠 가능성.
  3. 홈페이지 vs 리포트 차이: 홈페이지 요약은 비교 대상/지표를 일부 생략한 표 기준 "1위" 표기 사례 있음. 순위 인용 시 리포트 전체 표 확인 권장.
  4. 35B-A3B는 프리뷰: 학습 중인 버전. 리포트 분석 대부분은 2B/9B 기준.
