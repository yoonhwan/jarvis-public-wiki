한 줄 요약

Oracle Cloud Always Free에서 OCI CLI와 Codex를 활용해 A1 Flex 인스턴스를 생성·증설하여 최종적으로 4 OCPU / 24GB RAM 서버를 확보했다는 경험담.

원문

[오라클 클라우드 서버 무료로 얻기 성공기 1]

예전에 시도했던 오라클 클라우드 서버 무료로 얻기가 최근 성공해서 기록겸 나와 같은 어려움(?)을 겪은 분들에게 공유코자 정리하여 포스팅

<요약>

  1. 오라클 클라우드 가입
  2. 무료 티어 -> 유료로 변환(카드 등록만 하고 결제/취소 인증만 하면 비용 x)
  3. OCI CLI 설치 및 설정, 컴터 내에 관련 유저 ID 등록
  4. 코덱스에게 ‘OCI CLI로 무료 티어 한계까지 설정해서 만들어줘’ ‘너가 알아서 해줘‘ 시전
  5. 성공!
  1. 주말에 잠깐 여유가 생겨서 검색하다가

OCI CLI(Oracle Cloud Infrastructure CLI)가 있다는 사실을 발견!

오라클 클라우드 무료 서버는 예전부터 알고 있었는데,

콘솔에서 계속 눌러보는 방식 말고 CLI로 접근하면 코덱스가 직접 다룰 수 있겠다는 생각이 들었음.

그래서 코덱스에게

"OCI CLI로 접근할 수 있는 권한으로 무료 티어 서버 설정해줘"

라고 시킴.

  1. 사전에 필요한 건 있음.
  • Oracle Cloud 계정
  • OCI CLI 로그인/설정
  • 사용자 OCID
  • 테넌시 OCID
  • 리전 설정
  • VCN / subnet 같은 기본 네트워크
  1. 참고로 OCI 콘솔 안의 Cloud Shell을 쓰면

브라우저에서 바로 사전 인증된 OCI CLI를 쓸 수 있음.

나는 로컬에서 Codex CLI랑 같이 쓰려고

Windows에 OCI CLI를 설치해서 진행했음.

이 정도만 준비되어 있으면,

그 다음부터는 코덱스가 OCI CLI 명령을 만들어서 직접 확인하고 실행함.

  1. 처음 목표는 오라클 무료 티어에서 제일 좋은 A1 Flex.

“4 OCPU / 24GB RAM”

근데 역시나 바로 되지는 않음.

오라클 무료 티어 A1은 자리가 없다고 자주 튕김.

에러는 이렇게 나옴 “Out of host capacity”

즉, 내가 뭘 잘못한 게 아니라

춘천 리전에 지금 빈 자리가 없음

  1. 그래서 코덱스랑 전략을 바꿈.
  2. 먼저 4 OCPU / 24GB 시도
  3. 안 되면 2 OCPU / 12GB로 낮춰서 시도
  4. 그래도 안 되면 예약 작업으로 천천히 재시도
  5. 성공하면 텔레그램으로 알림

결론:

2~3회 정도 만에 2 OCPU / 12GB 무료 티어 서버 받음!

춘천 서버로 생성 성공.

  1. 여기서 끝내도 충분하다고 생각했는데, 스치니들이 최대치까지 써야한다고 해서.

같은 인스턴스를 다시 4 OCPU / 24GB로 증설하는 작업을 돌림.

이것도 OCI CLI로 처리함.

코덱스가 PowerShell 스크립트를 만들어서

현재 인스턴스 상태 확인 → 증설 요청 → 상태 재확인 → 성공 알림

이 흐름으로 자동화함.

중간에 중요한 포인트가 하나 있었음.

OCI가 "증설 요청을 수락했다"와

"실제로 4CPU/24GB로 바뀌었다"는 다름.

  1. 그래서 최종결과는…

Oracle Cloud Always Free

VM.Standard.A1.Flex

4 OCPU / 24GB RAM

Ubuntu 22.04 ARM

춘천 리전

자비스 관점 메모

  • 콘솔 수동 클릭이 아니라 OCI CLI를 준비해 Codex/에이전트가 리소스 생성·확인·재시도를 수행하게 한 사례.
  • A1 Flex의 Out of host capacity는 설정 오류가 아니라 리전 용량 부족일 수 있으므로, 스펙을 낮춰 생성 후 증설하거나 예약/재시도 흐름을 자동화하는 접근이 핵심.
  • “요청 수락”과 “실제 스펙 반영”을 구분해 상태 재확인을 넣은 점이 운영 자동화에서 중요하다.
