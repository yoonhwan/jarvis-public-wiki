Cohere Transcribe — Whisper보다 빠르고 정확한 무료 오픈소스 STT

한 줄 요약

OpenAI Whisper보다 오류율 27% 낮고 3.6배 빠른 오픈소스 STT 모델. 한국어 포함 14개 언어, Apache 2.0 무료.

핵심 비교 (Whisper vs Cohere Transcribe)

항목OpenAI Whisper Large v3Cohere Transcribe
WER (오류율)~7%~5% (27% 낮음)
RTFx (처리 속도)146525 (3.6배 빠름)
1시간 음성 처리 시간~25초~7초
라이선스MITApache 2.0
한국어 지원✅✅

속도 지표 (RTFx)

  • RTFx = 실시간 대비 처리 배수 (숫자 클수록 빠름)
  • 1분짜리 음성 파일을 0.1초에 처리하면 RTFx = 600
  • Cohere: RTFx 525 — 2시간 강의를 14초에 텍스트화 가능

인간 선호도 평가 결과

  • 전문 평가자가 각 모델 결과물 직접 비교
  • 평균 승률 61% (50% = 동률 기준)
  • IBM Granite 4.0 대비: 78% 승
  • NVIDIA Canary Qwen 2.5B 대비: 67% 승
  • 정확성, 의미 보존, 고유명사 인식, 형식 모두 평가

지원 언어 (14개)

한국어, 영어, 프랑스어, 독일어, 이탈리아어, 스페인어, 포르투갈어, 그리스어, 네덜란드어, 폴란드어, 아랍어, 베트남어, 중국어, 일본어

시스템 요구사항

  • 파라미터: 20억 개 (약 4~8GB VRAM)
  • NVIDIA GPU 권장, CPU도 동작 (느림)

설치 및 사용법

pip install "transformers>=4.56"
import torch
from transformers import AutoProcessor, AutoModelForSpeechSeq2Seq

model_id = "CohereLabs/cohere-transcribe-03-2026"
device = "cuda:0" if torch.cuda.is_available() else "cpu"

processor = AutoProcessor.from_pretrained(model_id, trust_remote_code=True)
model = AutoModelForSpeechSeq2Seq.from_pretrained(
    model_id, trust_remote_code=True
).to(device)
model.eval()
