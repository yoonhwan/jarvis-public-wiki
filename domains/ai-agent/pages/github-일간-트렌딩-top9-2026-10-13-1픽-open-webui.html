1픽: Open WebUI (셀프호스팅)

  • Ollama + OpenAI 호환 API(LM Studio·Groq·OpenRouter·vLLM 등)를 한 화면에서 사용
  • 문서 RAG, 웹 검색, 이미지 생성, 멀티모델 대화, 플러그인(Filters·Actions·Pipes·Tools·Skills) 지원
  • 설치:
  # Python 3.11
  pip install open-webui
  open-webui serve   # http://localhost:8080

  # Docker
  docker run -d -p 3000:8080 ghcr.io/open-webui/open-webui:main
  # :ollama 태그 = Ollama 동봉, :cuda 태그 = GPU용
  • 라이선스: Open WebUI License(이전 기여분 혼재) + 브랜딩 유지 조건 — 재배포 시 LICENSE/LICENSE_HISTORY 확인 필요

기타 주목 항목

  • God's Eye View: 항공기 ADS-B, 선박 AIS, 위성 궤도, 지진계, 공개 CCTV를 모은 3D 지구본. 계정/API 키 불필요. npm ci && npm run dev → localhost:4173. MIT(일부 데이터는 비상업 조건).
  • Context Mode: 코딩 에이전트 컨텍스트 과소비를 줄이는 MCP 서버(315KB→5.4KB, 98% 절감 예시). Claude Code: /plugin marketplace add mksglu/context-mode. Elastic License 2.0(호스팅 재판매 금지).
  • Free Claude Code (FCC): Claude Code/Codex/VS Code 등 11종 에이전트에 무료/유료/로컬 제공자 61곳을 연결. 비공식(Anthropic 무관) 프로젝트. AGPL-3.0.
  • AirLLM: 레이어 단위 GPU 로드/언로드로 4GB GPU에서 70B 모델 추론. pip install airllm. Apache-2.0.
  • BitNet (bitnet.cpp): MS 공식 1비트 LLM 추론 프레임워크. 소스 빌드 필요(즉시 실행형 아님). MIT.
