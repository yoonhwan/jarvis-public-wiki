DeepSeek이 자체 AI 추론 프레임워크 DeepInfer를 전면 오픈소스로 공개했습니다.

DeepSeek-V4.1-Flash를 실제 서비스에서 구동하는 데 사용되는 기술입니다.

AI 응답 속도를 높이고 연산 비용과 전력 사용량을 줄이기 위한 최적화 기술이 포함돼 있습니다.

공식 DeepSeek API와 동일한 방식으로 토큰을 처리하는 deepseek-recipe도 함께 공개했습니다.

앞으로 출시될 DeepSeek 모델의 추론 코드도 해당 저장소에 추가할 예정입니다.

저장소 상세 (GitHub README 보강)

항목내용
저장소deepseek-ai/DeepInfer
역할DeepSeek 대규모 프로덕션 서비스를 구동하는 고성능 추론 프레임워크 — 이번 공개는 오프라인 추론용 핵심 기능
지원 모델DeepSeek-V4.1-Flash (체크포인트: deepseek-ai/DeepSeek-V4.1-Flash-1017, HuggingFace)
지원 하드웨어NVIDIA SM100 GPU, Huawei Ascend 950 NPU
라이선스Apache License 2.0
기반vLLM 위에 구축, SGLang·TensorRT-LLM에서 아이디어 차용

핵심 기능

  • 최적화 커널: FlashMLA, DeepGEMM, DeepEP, TileKernels, DeepSelect, 커스텀 TileLang 커널
  • 병렬화: Attention DP / balanced CP, MoE EP + EPLB
  • DSpark + confidence-scheduled verification: draft 토큰으로 디코딩 가속, confidence 기반 검증 스케줄링 (DEEPINFERENABLEMTP_VARLEN=1)
  • SWA bounded replay: 디코더 prefill 작업을 bounded suffix만 재생해 축소
  • 비동기 스케줄링: CPU 배치 스케줄링과 디바이스 실행을 오버랩 (기본 활성화)
  • Batch-invariant inference / Deterministic sampling: 배치 구성과 무관하게 동일 결과 재현 (NVIDIA 전용, DEEPINFERBATCHINVARIANT=1)
  • Structured outputs: regex/JSON schema/EBNF grammar로 생성 제약

이 릴리스에 포함되지 않은 것 (완전한 추론 서비스에 추가로 필요):

  • KV 캐시 시스템
  • VE/Prefill/Decode 분리 배치
  • 데이터 병렬 replica 간 로드밸런싱

빌드/실행 (NVIDIA 기준)

# Ascend 플랫폼은 ascend로 교체, 환경변수는 실행 전체에서 유지 필요
export DEEPINFER_ACCELERATOR=nvidia
./build.sh

# 오프라인 추론 (기본 체크포인트는 최초 실행 시 HF 캐시로 자동 다운로드)
python examples/offline_inference.py

사전 요구사항: Linux, GCC ≥ 13.0, Python 3.12, CUDA 13(NVIDIA) 또는 CANN 9.2(Ascend)
