메타가 8년간 내부에서 쓴 디자인 시스템을 오픈소스로 풀었다 — Astryx.

1만 3천 개 넘는 앱을 지탱한 시스템으로, 접근성 갖춘 컴포넌트 150개 이상, 브랜드 테마·다크모드·템플릿·CLI를 한 묶음으로 제공한다. React 19+ 기반, TypeScript. 사람과 AI 에이전트가 같은 도구로 UI를 만든다는 게 특징이다.

쓸모: 코딩 에이전트와 함께 프론트를 만들 때, 컴포넌트부터 다시 짜지 않고 바로 조립할 수 있다.

링크: github.com/meta/astryx

GitHub README 요약 (meta/astryx, 별도 소스 보강)

특징 4가지

  1. Open internals: 컴포넌트를 어느 층위에서든 조합 가능. swizzle 로 컴포넌트 전체 소스를 프로젝트로 꺼내 직접 소유.
  2. No styling lock-in: 내부는 StyleX 로 작성하지만 사용자에게는 보이지 않음. Tailwind, CSS modules, plain CSS 의 className 으로 override.
  3. Customize without wrapping: 테마 = CSS custom property override 묶음. fork·wrapping 없이 브랜드화.
  4. Built for people and agents: API, 문서, CLI 를 함께 설계해 사람과 AI 어시스턴트가 같은 레퍼런스로 작업.

설치

npm install @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex
npm install -D @astryxdesign/cli

# CLI 전역 설치 (어떤 폴더에서도 astryx 사용, 코딩 에이전트가 Astryx 인식)
npm i -g @astryxdesign/cli
  • 설정은 CSS import 몇 줄 + theme provider. build plugin, PostCSS, Babel 설정 불필요.
  • Next.js, Tailwind, Vite, CDN 가이드는 packages/core/README.md Quick Start 참조.
  • 에이전트가 경로 오류 없이 CLI 를 부르게 하려면 package.json 에 script 추가: "astryx": "node node_modules/@astryxdesign/cli/clients/cli/bin/astryx.mjs" → npm run astryx -- component --list
  • 프로젝트/전역 설치 비교: astryx docs global/project-global-or-both (둘 다 설치 권장)

  • @astryxdesign/vega, @astryxdesign/charts 는 @canary dist-tag 로만 배포. stable 릴리스 없음.

원칙

  • Guidance over enforcement (가드레일보다 capability)
  • Strong, documented conventions (이름·prop·조합 규칙 통일)
  • One system for humans and AI
  • Earned by measurement (규칙을 측정으로 검증)
