로컬 LLM 돌릴 때 GPU 전력제한 걸면 성능 지장 없이 조용해짐 (RTX 3090 + vLLM + Qwen3.8-27B)

본문 (Main Post, @blueworkcom)

로컬 llm 돌리는 사람 주목!

전력제한 걸어 보세요. 성능 지장 없고 추론할때 조용해짐.

RTX 3090에서 qwen3.8 27b 모델 돌리는데.

기본 350와트를 250와트로 변경 했는데도 성능 똑같고

추론할때 gpu온도 많이 안올라가서 팬소음 조용해짐.

속도 실측: 싱글 ~110 tok/s, 3병행 각 ~99 tok/s

스펙/설정 요약

항목값
GPUNVIDIA GeForce RTX 3090, 24GB
전력제한250W (기본 350W), 현재 249W로 full-throttle
속도 (싱글)~110 tok/s
속도 (3병행)각 ~99 tok/s
렌더링 분리vLLM 전용 GPU — gnome은 iGPU(UHD 770) 렌더링
OSUbuntu 26.04.1 LTS (PVE 호스트 192.168.100.100의 LXC 컨테이너, CTID 100)
런타임Python 3.14 venv + vLLM 0.28.0
모델Qwen3.8-27B W4A16 (ababaka AutoRound) — abliterated, 비전포함
디코딩 옵션MTP k=3 스펙추레이션, 128K 컨텍스트, fp8 KV
포트18020

핵심 요지: 전력제한을 350W→250W로 낮춰도 추론 속도(tok/s)는 거의 동일 — GPU 온도가 안 올라가서 팬 소음만 줄어듦. 로컬 LLM 서버 운영 시 정숙성 확보를 위한 손쉬운 트레이드오프.
