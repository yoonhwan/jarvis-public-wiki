쓰는 법 — 3단계

  1. 프롬프트 복사 — 버튼 하나에 설치 명령 + 사용법 + 모든 props가 한 덩어리로 들어 있다.
  2. 에이전트에 붙여넣기 — Claude Code / Cursor / Codex가 설치하고 앱에 연결까지 한다.
  3. 다듬기 — 공개 플레이그라운드에서 조절, 더 깊게는 Studio(Pro).
