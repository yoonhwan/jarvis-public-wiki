AI로 만든 서비스, 개인정보처리방침 없으면 과태료 3000만원

박판다 (@panda__park_) on Threads
바이브코딩/AI로 서비스 만든 사람들이 놓치기 쉬운 개인정보처리방침 의무와 확인 프롬프트 공유

핵심 요약

상황리스크
개인정보처리방침 아예 없음과태료 최대 1천만원
방침은 써놓고 안 지킴 (탈퇴해도 실제 미삭제 등)과태료 최대 3천만원 (파기 의무 위반, 방침 없는 것보다 무거움)
코드는 수집하는데 방침에 미기재고지 없이 수집 → 또 다른 위반
  • 위 금액은 법정 상한이며, 실제로는 위반 횟수·정도에 따라 몇백만원 선부터 올라감
  • 로그인 기능 하나만 붙였어도 대상 (회사 규모 무관)

본문 (Main Post)

대상: "개인정보를 처리하는 자" 전부

  • 법에 매출·직원 수 기준이 없음 → 1인 사업자·비영리도 모두 포함
  • 개인정보 범위가 넓음: 이메일 주소 하나만 받아도 개인정보
  • 소셜 로그인은 설정에 따라 이름·프로필까지 수집, 접속 기록도 다른 정보와 합쳐 식별 가능하면 개인정보
  • 만들어서 배포까지 했으면 남 얘기 아님

진짜 문제: 내가 안 붙인 걸 AI가 알아서 붙임

  • AI에게 로그인 만들어달라 → 알아서 붙임, 통계 넣어달라 → 알아서 넣음
  • 그래서 내 앱이 뭘 받아 어디에 저장하는지 목록을 본 적이 없음
  • 모르면 방침도 못 씀 → 순서: 먼저 목록을 뽑고, 그다음 방침을 쓴다

공유 프롬프트

1️⃣ 수집 항목 목록 뽑기

내 프로젝트에서 사용자 정보를 받거나 저장하는 곳을 전부 찾아줘.
추측하지 말고 실제 코드에서 확인한 것만 표로 정리해줘.

1. 어떤 정보를 받는지 (이메일, 이름, 전화번호, 사진, 위치, 접속기록 등 전부)
2. 그걸 어디에 저장하는지
3. 받을 때 사용자한테 동의를 받는 절차가 있는지
4. 외부 서비스로 나가는 정보가 있는지 (로그인 연동, 통계 도구, 결제, AI 호출 등)
5. 지우는 기능이 있는지 (회원 탈퇴하면 실제로 지워지는지)

마지막에 사용자가 예상 못 할 만한 수집 항목이 있으면 따로 짚어줘.

2️⃣ 개인정보처리방침 초안 뽑기

위에서 정리한 수집 항목을 바탕으로
한국 개인정보보호법 기준 개인정보처리방침 초안을 써줘.

아래 항목이 다 들어가야 해.
- 수집하는 항목과 수집 목적
- 보유하고 이용하는 기간
- 파기 절차와 파기 방법
- 제3자에게 제공하는 내용
- 처리를 위탁하는 곳 (외부 서비스)
- 이용자가 열람, 정정, 삭제를 요구하는 방법
- 개인정보 보호책임자 연락처
- 쿠키 같은 자동 수집 장치와 거부 방법

실제로 내 코드에 없는 항목은 지어내지 말고
빈칸으로 두고 뭘 채워야 하는지 알려줘.

3️⃣ 대조 프롬프트 (방침 ↔ 코드 대조)

  • 이미 방침을 올려둔 경우, 방침 내용과 코드를 하나씩 맞춰봐야 함 (프롬프트는 별도 — 원 작성자에게 댓글/DM 요청)

주의사항 (작성자 당부)

  1. 법률 조언 아님 — 작성자도 개발자이지 변호사가 아님. 다만 최소한 내 앱이 뭘 수집하는지는 알고 있어야 함
  2. AI 초안을 그대로 올리지 말 것 — 실제 수집 안 하는 걸 적거나, 하는 걸 빠뜨리면 더 문제. 목록과 하나씩 맞춰보고 올릴 것
  3. 건강 정보·결제·아동 대상 서비스는 기준이 더 빡세므로 따로 확인

댓글 스레드 주요 내용 (Other Users)

  • 로그인 없어도 문의 기능이 있으면 개인정보처리방침 필요 + 수집·이용 동의 받아야 함. 동의 시 최소 4가지 노출: ①수집 목적 ②수집 항목(필수/선택) ③보유기간 ④미동의 시 안내
  • 바이브코딩만의 문제가 아님 — 아임웹·카페24 템플릿 납품 업체 중에도 안 해주는 곳 많았음 (창업·운영 경험 유무 차이)
  • 윅스 등 노코드로 만들어도 예외 없음 — 타인의 정보를 받는 모든 서비스가 해당
  • AI로 만든 사람 대부분 방침은 있는데 코드에 반영 안 됨 → 소비자에게 거짓말 하는 셈
  • 개인정보 수집은 정말 필요한 경우에만 최소한으로
  • 해외 서비스 고려 시 GDPR도 검토, 위탁 시 위수탁계약 확인 필요, 쿠팡사태 이후 관련 법규 강화 분위기
  • 혼자 쓰는 용도면 상관없음 / 타인 정보 수집 시 필수
