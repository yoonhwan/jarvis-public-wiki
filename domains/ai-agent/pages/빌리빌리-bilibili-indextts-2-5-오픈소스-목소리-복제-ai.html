본문 (Main Post)

빌리빌리가 목소리를 그대로 복제하는 AI 음성 모델을 오픈소스로 풀었어요.

  • 참고 음성 파일 하나만 있으면 돼요. 그 목소리로 원하는 문장을 그대로 읽게 만들 수 있어요. 따로 학습시키는 과정도 필요 없어요.
  • 감정이랑 말하는 속도도 세밀하게 조절돼요. 슬픈 톤, 놀란 톤도 넣을 수 있어요. 발표 슬라이드 타이밍에 맞춰 속도도 맞출 수 있어요.
  • 중국어·영어·일본어·스페인어·아랍어, 5개 언어를 지원해요.
  • 지금 오픈소스로 완전히 공개됐어요. 로컬에서 직접 설치해서 써볼 수 있어요.
  • 실험만 하고 끝나는 게 아니라, 실제 서비스로 배포하는 공식 경로도 마련돼 있어요.

1. 모델 소개 & 저장소

이름은 IndexTTS-2.5예요. 빌리빌리 팀이 만든 오픈소스 음성 복제 모델이에요.

  • GitHub: https://github.com/index-tts/index-tts
  • 이전 버전보다 속도가 더 빨라짐 — RTX 4090 기준 생성 속도 눈에 띄게 개선. 기능은 늘었는데 오히려 더 빨라짐.

2. 무엇이 달라지나

  • 목소리 복제: 예전엔 안내 음성 하나 만들려면 매번 직접 녹음 → 지금은 음성 파일 하나만 있으면 원하는 텍스트를 그 목소리로 바로 생성.
  • 더빙 작업: 예전엔 슬픈 장면마다 성우 톤을 새로 맞춰야 함 → 지금은 감정 레퍼런스 오디오나 감정 수치를 코드에 넣기만 하면 됨.

3. 왜 중요한가 (실서비스 배포 경로)

  • 실험용 데모로 끝나는 게 아님. vLLM 레시피가 공식으로 마련되어 있음 (vLLM = 대규모 모델을 서비스 트래픽에 맞게 서빙하는 추론 엔진) → 로컬 실험을 그대로 실서비스로 옮길 수 있음.
  • 오늘 바로 해볼 수 있는 것: uv run webui.py 한 줄이면 로컬 웹 화면 실행. 코드 없이 참고 음성 + 텍스트만 입력.
