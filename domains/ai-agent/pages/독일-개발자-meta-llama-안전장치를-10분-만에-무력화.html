한 줄 요약

한 독일 개발자의 GitHub 프로그램 하나로 Meta Llama의 안전장치가 10분 만에 제거되었으며, FT가 5/25 직접 테스트해 보도함. 이미 검열 해제된 모델 3,500개, 누적 다운로드 1,300만 회.

원문

오픈소스 AI 모델 까는 회사 직원이 봐야 할 게 있음. 독일 개발자 한 명이 깃허브에 올린 프로그램 하나가 메타 Llama 안전장치를 10분 만에 통째로 떼버림. 5월 25일 Financial Times가 직접 테스트해서 보도함. 이미 검열 해제된 모델 3,500개. 누적 다운로드 1,300만 회. 빅테크가 수백만 달러 들여 만든 안전장치가 프로그램 한 줄로 무너진 사건.
