Autoresearch — 프롬프트 자동 개선 방법론

요약

안드레 카파시가 고안한 "autoresearch" 방법론을 Claude Code와 Cowork에 적용해 프롬프트를 스스로 개선하는 스킬이 공개됐습니다.

이 스레드의 진짜 핵심은 본문 설명 + 작성자 하위 댓글의 프로젝트 링크 조합입니다.

본문은 개념 소개이고, 실제 구현체는 하위 댓글 GitHub 링크로 연결됩니다.

핵심 내용

  • 사용자가 '좋은 결과물'에 대한 Yes/No 체크리스트만 제공하면, 에이전트가 변수를 하나씩 바꾸고 점수를 매기며 최적 프롬프트 구조를 자동 탐색
  • 사례: 랜딩 페이지 카피라이팅 → 성공률 56% → 92% (사람 개입 없이)
  • 변경 기록(Changelog) 자동 생성 → 향후 더 좋은 모델 등장 시 기존 작업 이어가기 가능
  • 적용 범위: 프롬프트, 마케팅 카피, 아웃리치 메일, 웹사이트 속도 등 '측정 가능한 것' 전부

작성자 하위 댓글의 핵심 링크

  • GitHub: <https://github.com/olelehmann100kMRR/autoresearch-skill|olelehmann100kMRR/autoresearch-skill>

이 링크가 중요합니다.

스레드 본문만 저장하면 개념 메모로 끝나지만, 하위 댓글의 저장소 링크까지 받아와야 실제 재현/적용 출발점이 생깁니다.

참고 댓글

  • voidlight00 댓글은 autoresearch 루프를 구현 관점에서 조금 더 풀어 설명합니다.
    • eval.json에 참/거짓 테스트 작성
    • 루프 실행 → 점수 오르면 커밋, 내리면 롤백
    • 측정 가능한 품질은 자동 개선 가능, 톤/창의성 평가는 여전히 사람 몫
