요약

  • draw.io가 Claude 커뮤니티 커넥터로 출시 — 별도 설치/MCP 설정 없이 Claude 채팅창에서 "다이어그램 그려줘"라고 말하면 실시간 인터랙티브 draw.io 다이어그램으로 즉시 렌더링됨.
  • 채팅 안에서 확대/축소, 이동, 레이어 전환, 전체화면 모드 지원. 클릭 한 번으로 실제 draw.io 편집기에서 계속 편집 가능.
  • 지원 다이어그램: 플로우차트, 클라우드/SW 아키텍처, ER 다이어그램, 네트워크 토폴로지, UML, BPMN, 조직도, 목업 등. Mermaid 또는 draw.io XML 파일로도 생성 가능.
  • 도형 라이브러리 10,000개 이상 — AWS, Azure, GCP, Kubernetes, Cisco, 전기/P&ID 등 실제 브랜드 로고·아이콘 포함.
  • 계정 생성/가입 불필요.
  • ⚠️ 커뮤니티 커넥터는 자동 검토만 거쳤고 Anthropic 공식 검증은 받지 않음 — 신뢰하는 개발자만 연결 권장 (draw.io 카드 내 고지사항).

Codex 버전 (jgraph/drawio-mcp)

  • 원문 링크: https://github.com/jgraph/drawio-mcp/tree/main/plugins/codex/drawio
  • Codex CLI 플러그인으로, 네이티브 .drawio 파일을 생성. Codex가 다이어그램을 Mermaid(desktop CLI가 변환·레이아웃) 또는 draw.io XML(옵션으로 ELK 자동 레이아웃) 방식으로 직접 작성.
  • 출력 형식: PNG/SVG/PDF export(편집 가능하도록 XML 임베드), 또는 app.diagrams.net에서 바로 여는 브라우저 URL. 별도 MCP 셋업 불필요.
  • Claude Code plugin의 Codex 포트 — host wrapping(매니페스트 스키마, invocation, 로고)만 다르고 draw.io 가이던스 자체는 shared/에 있는 공용 SSOT.
  • 동작 방식:
    1. 작성 방식 선택 — 데스크톱 앱 설치 시 표준 다이어그램 타입(flowchart/sequence/class/state/ER/gantt/mindmap 등)은 Mermaid, 커스텀 스타일링/정밀 배치/특정 도형 라이브러리 필요 시 또는 데스크톱 앱 미설치 시 draw.io XML
    2. 네이티브 .drawio 파일 생성 — desktop CLI로 Mermaid 변환, 또는 XML 직접 작성(옵션으로 ELK --layout 패스 실행해 셀 배치 자동화)
    3. 요청된 출력 처리:
      • PNG/SVG/PDF → draw.io desktop CLI로 export
      • url → Node.js 내장 zlib으로 XML 압축 후 https://app.diagrams.net/#create=... 브라우저에서 열기 (.drawio` 파일은 로컬 사본으로 유지)
      • (default) → .drawio 파일 그대로 유지
    4. 결과 열기
