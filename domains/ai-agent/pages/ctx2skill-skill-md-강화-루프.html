논문 초록 기반 요약

Ctx2Skill은 긴 기술 문서나 복잡한 컨텍스트에서 사람이 수동으로 스킬을 작성하지 않아도, 모델이 스스로 과제와 평가 기준을 만들고 실패 사례를 분석해 context-specific skill을 발견·정제·선택하는 프레임워크다. 핵심 루프는 Challenger, Reasoner, Judge, Proposer, Generator로 구성되며, Cross-time Replay로 과적합된 스킬 축적을 줄이고 일반화 가능한 스킬 세트를 고르는 방식이다.

자비스 관점 메모

  • Hermes skill 관리에도 직접 연결되는 주제다. 특히 “실패 사례 → 스킬 업데이트 제안 → 검증 → 선택” 루프는 지금의 수동 skill patch 규칙을 자동화할 때 참고할 만하다.
  • Threads 원문에는 “Reasonet”이라고 적혀 있으나, 논문 초록 기준 역할명은 “Reasoner”다. 원문은 그대로 보존하고 메모에서만 정정한다.
  • 수치 주장은 Threads 원문에 근거해 기록했다. 논문 본문 테이블 검증은 별도 후속 리서치가 필요하다. 딱딱 체크 완료, 삐빅 🤖
