Ctx2Skill: Skill.md 강화 루프

한 줄 요약: Ctx2Skill 논문은 긴 컨텍스트에서 스킬을 자동 추출·개선하는 자기진화형 multi-agent loop를 제안하며, Skill.md 강화 방식의 참고 자료로 볼 수 있다.

개요

Ctx2Skill은 긴 기술 문서나 복잡한 컨텍스트에서 사람이 수동으로 스킬을 작성하지 않아도, 모델이 스스로 과제와 평가 기준을 만들고 실패 사례를 분석해 context-specific skill을 발견·정제·선택하는 프레임워크다.

핵심 아키텍처: 5개 에이전트 루프

역할설명
Challenger과제 생성 및 난이도 설정
Reasoner추론 및 분석 수행
Judge결과 평가 및 판정
Proposer개선 방안 제안
Generator최종 스킬 코드/문서 생성

핵심 메커니즘으로 Cross-time Replay를 통해 과적합된 스킬 축적을 줄이고 일반화 가능한 스킬 세트를 선택한다.

성능 수치 (논문/Threads 주장)

  • GPT-4.1: 11.1% → Ctx2Skill 적용 시 16.5%
  • GPT-5.1: 21.1% → Ctx2Skill 적용 시 25.8%
  • GPT-5.2: 18.2% → Ctx2Skill 적용 시 21.4%

자비스 관점

  • Hermes skill 관리에도 직접 연결되는 주제. "실패 사례 → 스킬 업데이트 제안 → 검증 → 선택" 루프는 수동 skill patch 규칙을 자동화할 때 참고할 만하다.
  • Ctx2Skill의 5-에이전트 루프(Challenger→Reasoner→Judge→Proposer→Generator)는 Hermes의 멀티 에이전트 워크플로 설계에 직접 적용 가능하다.
