오픈AI 'Decisions API' 퍼블릭 베타 공개

choi.openai (Threads) · 2026-10-07 수집

요약

오픈AI가 모델 선택, 문의 분류, 버튼 클릭 같은 실시간 판단을 전담하는 Decisions API를 퍼블릭 베타로 모든 개발자에게 공개했다. 텍스트+이미지 입력을 지원하며, 문장을 생성하는 기존 Responses API보다 최대 10배 빠르다.

핵심 포인트

항목내용
응답 형태문장 생성 대신 3가지 구조화 출력: predicate(조건 참 확률), choice(선택지+신뢰도), score(단계별 점수)
입력텍스트 + 이미지 동시 지원
모델현재 GPT-6 Luna 단일 모델
속도같은 Luna를 Responses API로 호출할 때보다 약 10배 빠름 (공식 시연 기준 150ms vs 1.6s 수준)
가격입력 100만 토큰당 $0.10, 출력/캐시 요금 없음 (Responses API는 출력 100만 토큰당 $0.50 별도)
정식 출시몇 주 내 예정

1/ Decisions API 개요

앱이 어떤 모델/도구/행동을 쓸지 같은 판단을 거의 실시간으로 내리게 하는 전용 API. 텍스트나 이미지를 넣고 질문을 정해두면 세 가지 형태로 답을 돌려준다:

  • predicate: 조건이 참일 확률 (예: 사진 속 캔이 찌그러졌는지 확률 1.00)
  • choice: 미리 정한 선택지 중 하나 + 신뢰도 (예: 도로 그림에서 2번 차선을 0.94로 선택)
  • score: 단계별 기준에 따른 점수

모델은 GPT-6 Luna 하나, Responses API 대비 약 10배 빠름. 정식 출시는 몇 주 내.

2/ 시연 — 영업 문의 분류

이메일마다 회사 유형·팀 규모·구매 단계·요구사항·일정·다음 단계를 한번에 판단. 여러 질문을 한 요청에 묶어 동시 처리 가능(판단 항목이 늘어도 호출 안 늘어남). 오픈AI는 확률 높은 결과는 자동 처리, 애매한 건만 사람에게 넘기도록 기준 확률을 실데이터로 정하라고 안내.

3/ 이미지 입력 — 화면 기반 선택

도로 화면 이미지를 넣고 장애물을 피해 차선(1/2/3번) 중 하나를 매 순간 선택하는 데모. 오픈AI 개발자경험팀 Charlie Guo가 공개한 비하인드 데모: 장소/날씨/시간대에 따라 옷장 사진에서 상의/하의/아우터/신발을 재선택 (API 처리 69ms, 결정 4개). 버튼 선택·입력 폼 이동 같은 에이전트 동작도 동일 방식.

4/ 음성 연동

Live API의 클라이언트 위임 기능과 결합 — 사용자가 말로 요청하면 Decisions API가 실행할 동작을 고르고 결과를 음성으로 재안내. GPT-Live-1(대화 담당)과 Decisions API(실행 판단 담당)로 역할 분리, 음성 요청→화면 동작 간 대기시간 단축이 목적.

5/ 가격 및 경쟁 비교

비교Decisions API (OpenAI)Jev (TypeSafe)
입력 단가 (100만 토큰)$0.10$0.042
출력 비용없음무료
특징데이터 미보관(ZDR), HIPAA, 미국/EU 처리 지역 지정 지원3주 먼저 출시, 텍스트 생성 불가 판단 전용 모델

Jev는 ChatGPT/RLHF 개발 참여자 Diogo Almeida가 2년간 개발한 의사결정 특화 모델(문장 생성 불가, 기존 LLM 대비 20~200배 빠르고 40~400배 저렴 주장). Decisions API 발표 직후 커뮤니티에서는 Jev와의 벤치마크 비교를 묻는 반응이 다수. 입력 단가는 Jev의 약 2.4배지만 ZDR/HIPAA/지역 지정 등 엔터프라이즈 요건은 OpenAI가 우위. 기존 OpenAI API 고객은 별도 계약 없이 바로 사용 가능.
