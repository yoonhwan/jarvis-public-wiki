본문 (Main Post)

Chonkie는 문서 청킹에 특화한 경량 파이썬 라이브러리입니다.

  • 10종 이상의 청커를 한 라이브러리에 담음: 토큰·문장·재귀·의미유사도·코드 구조 등
  • SIMD 가속 FastChunker로 100GB/s급 속도
  • Pipeline API로 청킹·오버랩 리파인·임베딩을 체인으로 연결한 후 async로 실행
  • 10개 이상 벡터 DB handshake 인터페이스로 곧바로 적재: Chroma·Qdrant·Weaviate·Milvus·pgvector·LanceDB 등
  • 기본 설치 크기 505KB 수준으로 가벼움
  • 56개 언어 지원
  • REST API 서버와 Docker 배포도 한 줄로 가능
