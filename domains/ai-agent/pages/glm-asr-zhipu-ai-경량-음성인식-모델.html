GLM-ASR — Zhipu AI 경량 음성인식 모델

속삭이는 목소리도, 저음량 환경도 정확히 인식한다면? 🎧

본문 (Main Post)

GLM-ASR은 Zhipu AI가 공개한 1.5B 파라미터 경량 음성인식(ASR) 모델입니다.

  • 표준 중국어와 영어는 물론 광둥어를 비롯한 중국어 방언 인식에 최적화
  • 속삭이듯 작은 목소리나 저음량 구간처럼 기존 모델이 놓치기 쉬운 음성도 비교적 안정적으로 전사
  • 17개 언어에서 실사용 가능한 수준의 정확도 (WER 20% 이하) 제공
  • Hugging Face transformers로 로컬 추론 가능
  • SGLang 서버로 OpenAI 호환 API 배포 구성 가능
