BananaTape - GPT 이미지 시각 편집 도구

핵심 메시지

GPT-Image-2.0 (duct-tape) 모델로 생성한 이미지를 그림 그리고, 화살표 찍고, 포스트잇 메모로 수정 지시하는 도구. "오른쪽 아래 거 지우라고!!" 같은 말로 설명하기 빡치는 수정 작업을 시각적 피드백으로 해결.

본문 원문

K-스킬 만들다가 최근 출시한 gpt-images-2.0 (duct-tape) 모델이 너무 좋아서, 더 편하게 쓰고 싶어서 만들었습니다. 소개합니다 : BananaTape
지피티가 기가 막히게 결과물을 생성해줘요. 다만, 수정하는 것이 조금 귀찮죠... "아니 오른쪽 아래에 있는 것을 지우라고!!" "그 위에 글씨를 조금만 가운데쪽으로 움직여줘" .... 말로 설명하기 빡칩니다 빡쳐요.
그래서 BananaTape는 그냥 생성된 이미지 위에 그리고, 화살표로 표시하고, 포스트잇으로 메모를 붙여서 수정을 합니다. 심플하고 빠르게 모델에게 피드백을 줘 보세요.
1. 의도적으로 가볍게 설계되었습니다. UI는 에디터에만, 나머지는 에이전트를 통해 CLI로 조작
2. OpenAI API key 필요 없습니다. 코덱스 구독 그대로 이용하세요
3. 수정 기록, 프롬프트 등 전부 저장
4. 추후 Magic Layer, 슬라이드 버전, 병렬 생성 등 추가할 예정

핵심 특징

  • 시각적 피드백: 그림/화살표/포스트잇으로 수정 지시
  • 가벼운 설계: UI는 에디터에만, 나머지 동작은 CLI 에이전트
  • API key 불필요: Codex 구독으로 그대로 사용
  • 이력 저장: 수정 기록과 프롬프트 전부 보존
  • 로드맵: Magic Layer / 슬라이드 버전 / 병렬 생성 예정
