cmux — 에이전트 코딩용 터미널 추천

원본: https://www.threads.com/@silsangv/post/DWApiabEexJ

요약

맥에서 cmux 터미널이 에이전트 코딩에 최적이라는 리뷰. tmux의 GUI 부재, Codex App의 느린 반응속도, VS Code의 프로젝트 탭 관리 문제를 모두 해결한 터미널이라는 평가.

핵심 포인트

  • cmux 장점:
    • tmux의 GUI 없는 불편함 해소
    • 중저사양에서도 빠른 반응속도 (Codex App 대비)
    • 프로젝트 단위 탭 관리 가능 (VS Code 대비)
    • 추가 탭으로 웹 브라우저도 사용 가능
  • cmux + pencil 조합: 현존 최고 에이전트 코딩 조합이라는 평
  • cmux 단점 (2가지):
    1. 프롬프트 마지막 명령어가 한글일 때 엔터를 두 번 쳐야 함
    2. 프로젝트 파일 구조를 볼 수 없음 (차후 수정 예상)
  • Ghostty 눈 건강 설정 팁:
  font-family = D2Coding
  font-size = 18

원문

맥에서 cmux 터미널 진짜 좋네여. gui가 없는 tmux의 불편함과 중저사양에서 반응속도가 굼뜬 codex app의 느린 속도와 프로젝트 단위로 탭에서 관리가 안되는 visual studio의 단점들을 모두 상쇄한 훌륭한 에이전트 코딩용 터미널. cmux 추가 탭으로 웹 브라우져도 쓸 수 있으니 개꿀~ 단점은 2가지인데 프롬프트 마지막 명령어가 한글일 때 엔터를 두 번 쳐야함. 하나는 프로젝트 파일 구조를 볼 수 없다는건데 차차 수정 해줄거라고 보고 당분간은 cmux에서 눕기로 결정함. cmux + pencil 조합은 현존 최고인듯 ㅎㅎ 노안 일찍 오지 않도록 Ghostty 설정에 아래 내용 추가합시다.
