Everything Claude Code (ECC)

원본: https://github.com/affaan-m/everything-claude-code/blob/main/docs/ko-KR/README.md

AI 에이전트 하네스를 위한 성능 최적화 시스템. Anthropic 해커톤 우승작.

50K+ stars | 6K+ forks | 30 contributors | 6개 언어 지원

핵심 개념

단순한 설정 파일 모음이 아닌, 스킬, 직관(Instinct), 메모리 최적화, 지속적 학습, 보안 스캐닝, 리서치 우선 개발을 아우르는 완전한 시스템.

10개월 이상 실제 프로덕트를 만들며 매일 집중 사용해 발전시킨 프로덕션 레벨 설정.

다루는 주제

주제내용
토큰 최적화모델 선택, 시스템 프롬프트 최적화, 백그라운드 프로세스
메모리 영속성세션 간 컨텍스트를 자동으로 저장/불러오는 훅
지속적 학습세션에서 패턴을 자동 추출 → 재사용 가능한 스킬로 변환
검증 루프체크포인트 vs 연속 평가, 채점 유형, pass@k 메트릭
병렬 처리Git worktree, 캐스케이드 방식, 인스턴스 확장 시점
서브에이전트 오케스트레이션컨텍스트 문제, 반복 검색 패턴

설치 방법

옵션 1: 플러그인 설치 (권장)

# 마켓플레이스 추가
/plugin marketplace add affaan-m/everything-claude-code

# 플러그인 설치
/plugin install everything-claude-code@everything-claude-code

⚠️ 룰은 수동 설치 필요:

git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code
./install.sh typescript  # 또는 python, golang

옵션 2: 수동 설치

git clone https://github.com/affaan-m/everything-claude-code.git
cp everything-claude-code/agents/*.md ~/.claude/agents/
cp -r everything-claude-code/rules/common/* ~/.claude/rules/
cp everything-claude-code/commands/*.md ~/.claude/commands/
cp -r everything-claude-code/skills/* ~/.claude/skills/

주요 기능

AgentShield — 보안 스캐닝

Claude Code 설정의 취약점, 잘못된 구성, 인젝션 위험 스캔 (1282개 테스트, 102개 규칙)

npx ecc-agentshield scan          # 빠른 스캔
npx ecc-agentshield scan --fix    # 자동 수정
npx ecc-agentshield scan --opus   # 3개 Opus 에이전트로 정밀 분석

직관(Instinct) 기반 학습

패턴을 자동 학습하여 신뢰도 점수가 있는 직관으로 변환

훅 런타임 제어

export ECC_HOOK_PROFILE=minimal|standard|strict
export ECC_DISABLED_HOOKS="pre:bash:tmux-reminder,post:edit:typecheck"

크로스 하네스 호환성

Claude Code, Cursor, OpenCode, Codex, Antigravity 지원

비용 절감 팁

{
  "model": "sonnet",
  "env": {
    "MAX_THINKING_TOKENS": "10000",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "50"
  }
}
  • sonnet 기본 사용 → ~60% 비용 절감
  • MAXTHINKINGTOKENS: 10000 → 요청당 사고 비용 ~70% 절감
  • AUTOCOMPACT 50% → 더 일찍 압축, 긴 세션에서 더 나은 품질
  • 깊은 아키텍처 추론이 필요할 때만 /model opus로 전환

MCP 주의사항

  • 프로젝트당 10개 미만 MCP 활성화
  • 80개 미만 도구 활성화 유지
  • 각 MCP 도구 설명이 200k 윈도우에서 토큰 소비 → ~70k까지 줄어들 수 있음
