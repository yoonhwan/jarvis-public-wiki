아무튼 한국어 UI에 최적화된 줄바꿈을 하려면 어절 단위 즉, 띄어쓰기 단위로 줄넘김 처리를 해줘야 가독성이 높아져요.

이럴 때 CSS 속성을 사용하면 좋은가?!

바로 word-break, text-wrap, overflow-wrap, white-space입니다.

1. word-break

word-break는 줄바꿈 후보를 지정합니다. 그래서 음절 단위로 할 건지, 어절 단위로 할 건지 정할 수 있어요.

한국어 국룰 줄바꿈 처리는 word-break: keep-all 을 적용합니다.

word-break만 처리해줘도 많이 나아지지만 아쉬운 부분들이 있습니다. 예를 들어:

언제 어디서나 편하게 여행을
즐기세요.

위처럼 줄바꿈을 하면 어절 단위 줄바꿈은 적용됐지만 줄끼리의 길이도 다르고 읽을 때도 호흡이 달라져 어색합니다.

그럴 땐 text-wrap 속성을 함께 사용하면 좋습니다.

2. text-wrap

text-wrap은 어디서 줄바꿈 하는 게 예쁘게 보일지 정합니다. 주로 쓰면 좋은 건 balance, pretty입니다.

  • balance: 줄바꿈 했을 때 각 줄의 길이가 최대한 일정해지도록 맞춥니다.
  언제 어디서나 편하게
  여행을 즐기세요.

보다 읽기 편해져서 제목 같은 곳에 쓰기 좋음.

  • pretty: 전체 줄의 길이감이 아니라 맨 마지막 줄에 오는 단어가 하나만 남지 않도록 처리. 본문에 쓰기 좋음.

최근 Figma에도 text-wrap 속성이 추가되어서 디자인할 때도 적용 가능.

3. white-space

한국어 UI 전용 속성은 아니고, 줄바꿈을 할 거냐 말 거냐를 정하는 속성.

  • 줄바꿈 하지 말아야 하는 UI(버튼 레이블 등) 또는 댓글/리뷰/게시글처럼 유저가 직접 줄바꿈한 걸 그대로 보여줘야 할 때 사용.
  • white-space: nowrap: 줄바꿈 안 함 → 버튼 레이블 등에 적합
  • white-space: pre-line: 입력된 줄바꿈은 보여주되 실수로 들어간 공백은 정리
  • (입력 텍스트를 그대로 보여주려면 pre-wrap 사용)

4. overflow-wrap

단어가 너무 길어서(개인정보처리방침 같이 안 띄어 쓰는 긴 용어) 컨테이너에 넘칠 때 줄을 넘겨버리는 속성.

  • overflow-wrap: break-word: 단어가 컨테이너 길이를 벗어날 것 같으면 줄바꿈
  • overflow-wrap: anywhere도 있지만 작성자도 break-word와의 차이를 명확히 모른다고 함
