saju 🔮 — Claude Code / Codex 무료 AI 사주 스킬

@be_realdeveloper(B개발자)가 만든 오픈소스 사주 스킬. 저가 API 사주 앱 대신,
클로드 코드/Codex에 스킬을 붙여 무료로 유료 앱 수준의 평생사주 18장 + 상담 모드를 제공한다.

본문 (Main Post)

요즘 AI 사주가 너무 판치길래
굳이 저가 API로 사주를 볼 필요가 있을까라는
생각이 들어 만들어본 사주 스킬
실제로 인기있는 사주들의 목차를 바탕으로
총 18 챕터로 만들었음
클로드 코드 있으면 이제 사주는 무료로 보자

원문 프로필 링크: https://github.com/be-realdeveloper/saju**

핵심 개념

항목내용
무엇Claude Code / Codex용 사주 스킬 (오픈소스, MIT)
차별점진짜 만세력 엔진으로 절기 경계까지 정확히 명식 계산 → 실제 팔자·오행·십신·대운 데이터에 근거한 해석
산출물평생사주 풀이 18장 + 풀이 후 상담 모드(무엇이든 질문)
엔진Node.js만 있으면 됨. lunar-javascript(MIT) 동봉 → npm 설치 불필요
원리LLM이 사주를 암산하지 않음 — 엔진이 계산, LLM은 해석만

뭘 해주나

  1. 명식 계산 — 생년월일시·성별(양/음력·윤달) 입력 → 사주팔자·일간·오행·십신·격국·용신·대운·12운성·신살 계산. 진태양시(경도) 보정 기본 적용.
  2. 평생사주 18장 — 포스텔러·점신류 유료 앱 표준 목차를 길고 진하게.
  3. 상담 모드 — 18장 종료 후 "올해 이직해도 될까요?", "그 사람이랑 맞아요?" 등 같은 명식 근거로 계속 답변.

평생사주 목차 (18장)
1. 총평2. 성격·기질3. 오행 밸런스
4. 십신 구조5. 격국과 그릇6. 용신(평생의 약)
7. 대운 인생그래프8. 재물운9. 직업·적성
10. 학업·시험11. 애정·결혼12. 건강운
13. 대인관계·인복14. 가족운15. 신살 풀이
16. 평생 길흉 캘린더17. 개운법18. 마무리 조언

왜 "진짜" 같은가

  • 인기 감명 순서를 따름: 일간 → 신강/신약 → 오행(없는 오행) → 십신(없는 십신) → 격국·용신 → 신살 → 대운.
  • 궁위론 — 같은 십신도 어느 기둥(연=조상·초년 / 월=부모·사회 / 일=나·배우자 / 시=자식·말년)에 있느냐로 영역 구분 해석.
  • 근거 사전 동봉 — references/interpretation.md에 일간 10종·십신 10종·12운성·신살·오행↔건강 매핑 → 풀이 일관성.

시주(時柱) 정확도 — 진태양시 보정

많은 무료 만세력은 시계 시각 그대로 계산해 경계 시각 출생자의 시주가 틀어진다. 한국 표준시는 동경 135°(일본 아카시) 기준이지만 한국 실제 위치는 약 127°라, 진태양시는 시계보다 약 30분 늦다.

보정 공식: 보정(분) = (출생지 경도 − 135) × 4

입력보정
(기본, 출생지 미상)서울 경도 → 약 −30분(−32분)
부산 대구 인천 광주 대전 제주 …출생지 경도로 보정 (부산 −24분 등)
경도127.5 또는 --lon=127.5경도 직접 지정
표준시 또는 --no-lon보정 끄기(시계 시각 그대로)
예) 1995-08-15 15:00(서울) → 보정 없으면 申시(庚申), −30분 보정 시 14:28 → 未시(己未). 경계 시각일수록 차이 큼.

안전 원칙

점집이 아니라 참고용 분석 도구.

  • 🚫 수명·중병·이혼·파산 단정 금지 (건강은 "약한 장부·관리 포인트"까지만)
  • 🚫 부적·굿·비싼 개명 강매 금지 — 개운법은 색·방위·생활습관 등 무해한 처방까지만
  • 🙅 타인 사주를 본인 동의 없이 단정 안 함. 궁합은 "경향·포인트"로
  • 📌 모든 풀이 끝에 "참고이며 인생은 본인의 선택으로 바뀐다" 면책

설치

git clone https://github.com/be-realdeveloper/saju.git
cd saju
bash install.sh          # ~/.claude/skills/saju 로 복사
