어제(4월 16일), 알리바바가 Qwen3.6-35B-A3B를 공식 오픈소스로 풀었습니다.

  • Apache 2.0 라이선스 — 상업적 자유 사용 가능
  • 그런데 스펙을 보니까 숨이 턱 막히더라는 것

1. 파라미터 구조 (MoE)

항목값

활성 파라미터30억 (단 30억!)

"필요할 때만 필요한 전문가를 부른다" — 치과 진료에 종합병원 의사 전체를 부르지 않는 것과 같은 원리.

현업 PR 올리고 테스트 통과 비율 — 10건 중 7건 이상 해결.

4. Claude Code에 바로 연결 (핵심)

환경변수 두 줄만 바꾸면 됩니다:

ANTHROPIC_BASE_URL=https://dashscope-intl.aliyuncs.com/apps/anthropic
ANTHROPIC_MODEL=qwen3.6-flash

코드 수정 한 줄도 없이 Qwen을 Claude Code에 꽂을 수 있음.

6. 컨텍스트 & 모드

  • 컨텍스트 131,072 토큰 — 책 한 권(약 10만 단어)을 통째로 넣고 요약 가능
  • Thinking / Non-thinking 모드 전환 가능 (한 모델로 둘 다)

7. 로컬 실행 성능

8. 효율성

30억 활성 파라미터로 270억 덴스 모델(Qwen3.5-27B) 수준을 넘어섬 — 10배 작은 컴퓨팅으로 10배 큰 모델을 이긴 셈. MoE의 진짜 가치.

정리 (요약)

  1. 에이전틱 코딩 새 1위 (Terminal-Bench 51.5)
  2. Claude Code 설정 2줄로 즉시 전환 가능
  3. 비전 성능에서 Claude Sonnet 4.5 추월
  4. 24GB GPU 한 장으로 로컬 실행
  5. Apache 2.0 상업 사용 자유
  6. 컨텍스트 13만 토큰
Claude만 쓰던 사람도 이제 Qwen을 대체재로 놓을 수 있게 됨 — 비용이 10분의 1.
다음 주부터 OpenClaw 설정에 Qwen을 백업 옵션으로라도 추가 권장.
