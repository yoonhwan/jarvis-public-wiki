Claude Code 쓴다면 tmux 필수 설정 팁

📋 요약

Claude Code 사용자를 위한 tmux 꿀팁. tmux는 하나의 터미널에서 여러 터미널을 관리하는 도구로, Claude Code의 터미널 사용 수요 증가에 맞춰 핵심 설정 2가지를 공유.

💡 핵심 내용

tmux를 사용해야 하는 이유

  • 터미널 창 관리 매우 쉬움
  • 실수로 터미널 종료해도 상관없음 (세션 유지)

필수 설정 2가지

# ~/.tmux.conf에 추가
set -g mouse on
set-option -g history-limit 50000
  1. set -g mouse on — 마우스 지원 활성화
    • 설정 안 하면 창간 이동, 위로 스크롤을 마우스로 할 수 없음
  1. set-option -g history-limit 50000 — 스크롤 히스토리 확장
    • 기본값 2000줄 → 50000줄로 확장
    • 긴 작업 시 히스토리를 못 보는 경우 방지
