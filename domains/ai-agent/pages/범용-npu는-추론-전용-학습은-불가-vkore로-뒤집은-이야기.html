본문 (Main Post)

범용 NPU는 추론 전용, 학습은 불가. 이게 정설이다.

직접 재 보니 B200 1장이 1시간에 끝낼 트랜스포머 LoRA 학습을 서버 CPU는 약 320시간, NPU 기본 방식은 그보다 더 걸렸다.

그런데 말입니다!

「NPU용 쿠다」 개념 VKORE를 직접 만들어 붙였다. 칩은 그대로, 소프트웨어만 바꿨다.

① 추론 가속

항목BeforeAfter배수
1인 응답 속도14.1 토큰/초53.9 토큰/초3.8배
서버 동시 처리214 토큰/초881 토큰/초4.1배
동시성-동시 64명이 몰려도 1인 속도 유지-

② 학습 가속 (불가능 → 가능)

  • 표준 PyTorch 학습과 같은 정확도 (일치도 0.9999)
  • NPU 서버 1대가 같은 서버 CPU보다 약 180배 빠름
  • B200 1장의 약 55~60% 수준 😃 (가격대가 비슷한 장비끼리 비교)

낮에는 추론, 밤에는 같은 칩으로 학습하는 그림이 가능해진다.

NPU 학습은 엔비디아에게 가장 아픈 지점일 것이다 🥸
