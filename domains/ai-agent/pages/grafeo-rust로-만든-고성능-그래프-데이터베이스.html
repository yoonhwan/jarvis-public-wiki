Grafeo — Rust로 만든 고성능 그래프 데이터베이스

원본: https://www.threads.com/@conanssam/post/DWN4w39AQzV

요약

Grafeo는 Rust로 처음부터 만든 그래프 데이터베이스. 임베디드 라이브러리로도, 독립 서버로도 운영 가능하며 벤치마크상 Neo4j 대비 약 10배 빠른 성능을 보임.

핵심 포인트

1. 다양한 쿼리 언어 지원

  • 그래프 모델: LPG (Labeled Property Graph) + RDF 동시 지원
  • 쿼리 언어: GQL, Cypher, Gremlin, GraphQL, SPARQL, SQL/PGQ — 하나의 엔진에서 모두 사용 가능

2. AI 워크로드 통합

  • 벡터 검색 (Vector Search)
  • BM25 텍스트 검색
  • 하이브리드 검색
  • → 그래프 + AI 워크로드를 한 번에 실험 가능

3. 배포 유연성

  • 임베디드 라이브러리 (in-process)
  • 독립 서버 (standalone)
  • 인메모리 또는 영구 스토리지 선택
