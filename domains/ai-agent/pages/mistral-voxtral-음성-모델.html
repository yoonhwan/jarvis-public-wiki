📌 개요

Mistral AI가 Whisper를 대체할 차세대 오픈소스 음성 모델 Voxtral 시리즈를 출시했습니다.

  • Apache 2.0 라이선스 - 완전 오픈소스, 상업적 활용 가능
  • SOTA 성능 - Whisper large-v3, GPT-4o mini, Gemini 2.5 Flash 능가
  • 초저비용 - Whisper 대비 절반 이하 비용
  • 멀티모달 - 음성 + 텍스트 동시 처리

🎯 Voxtral 모델 라인업

1️⃣ Voxtral Small (24B)

프로덕션급 음성 이해 모델 - 고성능 애플리케이션용

핵심 스펙

  • 모델 크기: 24B 파라미터
  • 컨텍스트: 32k 토큰 (최대 40분 오디오)
  • 멀티모달: 음성 + 텍스트 동시 처리
  • 백본: Mistral Small 3.1 기반

주요 기능

  • ✅ 전용 전사 모드 (Transcription-only mode)
  • ✅ 음성 Q&A - 오디오에 대한 질문에 직접 답변
  • ✅ 요약 생성 - 별도 ASR+LLM 체인 불필요
  • ✅ Function Calling - 음성 명령으로 API 직접 호출 (실험적)
  • ✅ 텍스트 능력 유지 - 백본 LLM 성능 그대로

벤치마크 성능

FLEURS 벤치마크 (9개 언어 평균 WER):

  • Voxtral Small: 전 언어에서 Whisper large-v3 능가
  • 특히 유럽 언어에서 SOTA 달성 (영어, 프랑스어, 독일어, 스페인어, 이탈리아어, 포르투갈어, 네덜란드어)

영어 성능:

  • Short-form (<30초): ElevenLabs Scribe 수준 또는 초과
  • Long-form (>30초): GPT-4o mini, Gemini 2.5 Flash 능가

오디오 이해 (Audio Understanding):

  • GPT-4o mini, Gemini 2.5 Flash와 경쟁적
  • Speech Translation에서 SOTA 달성

텍스트 성능:

  • Mistral Small 3.1 백본 성능 유지
  • Drop-in replacement 가능

특징

  • 🔹 로컬 노트북/엣지 디바이스에서 실행 가능
  • 🔹 Voxtral Small과 동일한 기능 세트

3️⃣ Voxtral Mini Transcribe

API 전사 최적화 모델 - 비용 효율 극대화

핵심 스펙

  • API 가격: $0.001/분 (Whisper 대비 50% 절감)
  • 지연시간: OpenAI Whisper 대비 절반 이하
  • 전사 전용: 텍스트 생성에 최적화

성능

  • Mozilla Common Voice: SOTA 성능
  • 영어 short-form: Whisper large-v3 능가
  • 가성비: OpenAI Whisper 절반 비용으로 더 나은 성능

4️⃣ Voxtral Realtime (4B)

실시간 스트리밍 전사 모델 - 대화형 AI 에이전트용

핵심 스펙

  • 초저지연: 200ms 미만 설정 가능
  • 듀얼 스트림: 오디오 + 텍스트 동시 처리
  • 다국어: 13개 언어 지원
  • 성능: 대부분의 비스트리밍 모델 능가

특징

"Talk naturally. Talk fast. Talk ridiculously fast. Voxtral can handle it."

🎤 화자 분리 (Speaker Diarization)

현재 상태 (2026-02-08 기준)

✅ API 지원 (실험적)

Voxtral Mini Transcribe API에서 diarize 파라미터 제공:

response = client.audio.transcriptions.create(
    model="voxtral-mini-latest",
    audio=audio_file,
    diarize=True  # 화자 분리 활성화
)

제한사항

  • ⚠️ Realtime과 호환 불가 - 스트리밍 모드에서는 diarize 미지원
  • ⚠️ 화자 ID 정확도는 실험적 단계

🛠️ 고급 기능

1. Context Biasing (컨텍스트 바이어싱)

용도: 고유명사, 기술 용어, 도메인 특화 어휘 정확도 향상

response = client.audio.transcriptions.create(
    model="voxtral-mini-latest",
    audio=audio_file,
    context_bias=[
        "Kubernetes",
        "FastAPI",
        "LangGraph",
        "yoonhwan"
    ]
)

제약:

  • 최대 100개 단어/구문
  • 영어에 최적화 (다른 언어는 실험적)

2. Timestamp Granularity

세그먼트/단어 단위 타임스탬프

response = client.audio.transcriptions.create(
    model="voxtral-mini-latest",
    audio=audio_file,
    timestamp_granularities=["segment", "word"]
)

제약:

  • ⚠️ language 파라미터와 동시 사용 불가 (둘 중 하나만 선택)

3. Function Calling (실험적)

음성 명령으로 백엔드 함수 직접 호출

tools = [{
    "type": "function",
    "function": {
        "name": "get_weather",
        "description": "Get current weather",
        "parameters": {
            "type": "object",
            "properties": {
                "location": {"type": "string"},
                "format": {"type": "string", "enum": ["celsius", "fahrenheit"]}
            },
            "required": ["location", "format"]
        }
    }
}]

response = client.chat.completions.create(
    model="voxtral-small-latest",
    messages=[{
        "role": "user",
        "content": [{"type": "audio", "audio": audio_chunk}]
    }],
    tools=tools
)

활용:

  • 음성 기반 워크플로우 자동화
  • 대화형 AI 에이전트에 액션 트리거
  • 음성 → API 호출 직결 (ASR+NLU 체인 불필요)

4. Realtime Transcription

실시간 스트리밍 전사

from mistralai.realtime import RealtimeClient

client = RealtimeClient(api_key="...")
async for chunk in client.transcribe_stream(audio_stream):
    print(chunk.text)  # 실시간 전사 결과

특징:

  • 200ms 미만 레이턴시
  • 스트리밍 입력/출력
  • ⚠️ diarize와 호환 불가

현재 STT 아키텍처 검토 중인 상황에서 Voxtral을 고려할 만한 이유:

✅ 장점

  1. 비용 효율: Groq 10초 최소과금 문제 없음 (실제 사용량만 과금)
  2. 실시간성: Voxtral Realtime (200ms) + VAD → 중간 결과 표시 가능
  3. 다국어: 태국어 제외 8개 언어 SOTA (Groq와 동등 이상)
  4. 오픈소스: 로컬 배포 가능 → 민감 데이터 처리 시 유리
  5. Function Calling: 음성 → 액션 직결 (PTT 버튼 시나리오에 적합)

⚠️ 단점

  1. 태국어 미지원 (현재 9개 언어만)
  2. Function Calling 실험적 단계 (프로덕션 안정성 미검증)
