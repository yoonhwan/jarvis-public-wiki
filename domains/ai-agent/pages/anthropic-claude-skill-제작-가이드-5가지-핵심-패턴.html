요약

Anthropic이 직접 작성한 Claude Skill 제작 매뉴얼의 핵심 내용을 @keunyoung이 한국어로 정리한 쓰레드. Claude에게 반복되는 설명을 Skill로 자동화하고, 더 좋은 결과를 얻기 위한 5가지 핵심 패턴을 다룬다. Skill은 Claude가 특정 워크플로우를 일관되게 따르도록 가르치는 방법이며, 단독 사용 또는 MCP 연동 모두 가능하다.

5가지 핵심 패턴

1. 순차 워크플로우 조정 (Sequential Workflow Orchestration)

단일 시스템 내에서 정해진 순서대로 단계를 실행하는 패턴.

예시: 고객 온보딩 → 계정 생성 > 결제 설정 > 구독 생성 > 이메일 발송

  • 각 단계가 이전 단계의 결과(예: 계정 ID)를 사용
  • 중간 실패 시 완료된 부분을 롤백
[!tip] 핵심 포인트
- ✅ 단계 간 의존성을 명확히 정의하라 — 계정 ID 없이는 결제 설정 불가능
- ✅ 실패 시 롤백 범위를 미리 정해두라 — 결제 실패 시 생성된 계정도 삭제할지 결정

2. 멀티 MCP 조정 (Multi-MCP Coordination)

여러 외부 서비스를 넘나들며 작업하는 패턴.

예시: Figma에서 디자인 추출 > Drive에 저장 > Linear에 작업 생성 > Slack으로 알림

  • 1번과의 차이: 각 단계가 다른 서비스를 호출
  • 핵심은 서비스 간 데이터 전달 (Figma → Drive URL → Linear 첨부)
[!tip] 핵심 포인트
- 각 서비스 호출 후 응답 검증 필수
- 한 서비스 실패 시에도 전체가 멈추지 않는 에러 처리 설계

3. 반복 개선 (Iterative Refinement)

품질 기준 충족까지 검증-수정을 반복하는 패턴.

예시: 리포트 생성 → 초안 작성 > 품질 검증 > 문제 수정 > 재검증 (기준 만족까지)

[!tip] 핵심 포인트
- 구체적 품질 기준 설정 — "좋은 리포트" ❌ → "필수 섹션 5개, 모든 차트에 출처, 오타 0개" ✅
- 무한 루프 방지 — 최대 3회 같은 반복 제한 설정

4. 상황 인식 도구 선택 (Context-Aware Tool Selection)

같은 작업이지만 조건에 따라 다른 도구를 자동 선택하는 패턴.

예시: 파일 저장 시 → 10MB 이상이면 클라우드 / 협업 문서면 Notion / 코드 파일이면 GitHub

  • 3번과의 차이: 반복이 아닌 조건 분기
[!tip] 핵심 포인트
- 명확한 결정 기준 (파일 크기, 타입, 협업 필요) 정의
- 선택 이유 설명 — "15MB라서 클라우드에 저장했습니다" (투명성 = 신뢰)
- 대체 옵션 준비 — 클라우드 실패 시 로컬 저장

5. 도메인 전문 지능 (Domain-Specific Intelligence)

전문가의 판단 기준을 규칙으로 만들어 자동화하는 패턴.

예시: 결제 처리 → 제재 리스트 확인 > 국가별 규정 검토 > 사기 위험 평가 > 모두 통과 시 진행

  • 1~4번이 작업 흐름이라면, 5번은 도메인 지식 자동화
[!tip] 핵심 포인트
- 전문가 체크리스트를 규칙으로 코드화
- 모든 과정을 문서화하여 감사 추적 가능
- 금융, 의료, 법률 등 규정 준수가 중요한 분야에 특히 유용

Anthropic 공식 가이드 개요

Skills let you teach Claude your workflows once and apply them consistently.

공식 가이드가 다루는 내용:

  • 기술 요구사항 및 Skill 구조 모범 사례
  • 단독 Skill + MCP 연동 워크플로우 패턴
  • 다양한 유즈케이스에서 검증된 패턴
  • 테스트, 반복 개선, 배포 방법

대상 독자:

  • 일관된 워크플로우를 원하는 개발자
  • MCP 커넥터에 워크플로우를 추가하려는 빌더
  • 반복 작업을 자동화하려는 파워 유저
  • 조직 표준화를 원하는 팀
[!note] 소요 시간
자동화할 상위 2~3개 워크플로우를 알고 있다면, skill-creator를 사용해 약 15~30분이면 첫 번째 Skill을 만들고 테스트할 수 있다.
