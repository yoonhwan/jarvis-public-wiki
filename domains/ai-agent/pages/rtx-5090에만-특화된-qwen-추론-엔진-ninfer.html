RTX 5090에만 특화된 Qwen 추론 엔진이 나왔어요!

NInfer는 RTX 5090(sm_120a) 전용으로 범위를 의도적으로 좁히고 단일 GPU 성능에 집중했습니다. 멀티 GPU, 분산 서빙, 가중치 오프로드는 제품 범위에서 명시적으로 제외했어요.

MTP 추측 디코딩과 DFlash 드래프트, 청크 프리필을 지원하고, Qwen3.6-35B-A3B 기준 MTP3 단일 요청 디코드에서 642.5 tok/s를 기록했습니다. 정확한 프롬프트 접두사 단위로 KV와 연속 상태를 체크포인트로 저장해, 같은 접두사로 시작하는 요청에서 다시 활용해요.

OpenAI·Anthropic 호환 API에는 도구 호출 파싱과 토큰 카운팅까지 포함되어 있습니다. 개인이 관심으로 진행하는 프로젝트예요.

GitHub : https://github.com/Neroued/ninfer

빌드 요구사항

  • 64-bit Linux
  • NVIDIA GeForce RTX 5090 (CUDA sm_120a 고정)
  • CUDA Toolkit ≥ 13.1
  • CMake ≥ 3.28, C++20 컴파일러, Ninja, pkg-config
  • FFmpeg dev libs (libavformat>=60, libavcodec>=60, libavutil>=58, libswscale>=7)
  • libcurl >= 7.85

빌드 & 실행 예시

git clone https://github.com/Neroued/ninfer.git
cd ninfer

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j

Hugging Face에서 아티팩트 다운로드:

hf download neroued/Qwen3.8-27B-nvfp4-NInfer \
  qwen3_8_27b_nvfp4.ninfer \
  --local-dir models

서빙 예시 (텍스트/에이전트 서버, 동시 요청 2 레인):

./build/apps/ninfer-serve models/qwen3_8_27b_nvfp4.ninfer \
  --max-context 240000 \
  --kv-capacity 240000 \
  --max-concurrency 2 \
  --kv-dtype fp8 \
  --device-state-slots 2 \
  --host-state-slots 8 \
  --host-kv-mib 8192 \
  --spec mtp --draft-tokens 3 \
  --lm-head-draft \
  --preserve-thinking
