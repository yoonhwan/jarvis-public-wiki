한 줄 요약

서버가 요청을 처리하는 과정을 단계별 애니메이션 다이어그램으로 직접 조작하며 배우는 무료 시스템 설계 강의. 로그인 없이 브라우저에서 바로 시작하고, 9개 챕터 40개 레슨을 한국어를 포함한 21개 언어로 제공한다.

레슨이 굴러가는 방식

첫 레슨 「요청의 여정」을 직접 열어 확인한 구조다.

  1. 문제 제시 — "사용자들이 쇼핑몰이 느리다고 해요" 같은 상황이 먼저 나온다.
  2. 단계 진행 — 레슨당 10단계. 요청의 여정은 Enter 누르기 → 주소 찾기 → 연결 → 요청 → 데이터 가져오기 → 응답 → 파일 더 → 느린 쿼리 → 먼 곳 → 정리.
  3. 지표가 같이 움직인다 — DNS 조회·연결·요청+서버·다운로드 구간별 시간이 다이어그램 옆에서 실시간으로 바뀐다.
  4. 핵심 한 줄 — "모든 웹 요청은 기계들 사이의 대화예요. 단계마다 시간이 들고, 그 비용이 쌓입니다."
  5. 배울 내용 정리 — 그 레슨에서 가져갈 개념 4~5개.

조작은 마우스 외에 키보드도 된다. ← → 단계 이동, Space 일시정지, R 다시 보기, Esc 닫기.
