본문 (Main Post, @choi.openai)

NVIDIA가 음성에서 주변 소음과 울림을 제거하는 AI 모델 NVIDIA-NemotronLabs-RE-USE를 공개했습니다.

특히 주목할 점은 매개변수가 960만 개에 불과하다는 점인데요. 작은 모델로도 잡음이 섞인 음성을 선명하게 만들 수 있습니다.

여러 언어를 지원하며, 화상회의나 음성 녹음의 품질을 개선하는 데 활용할 수 있습니다.

현재 Hugging Face에서 모델을 다운로드하고 데모를 체험할 수 있습니다.

처리 가능한 열화

  • 배경 소음, 잔향, 클리핑, 대역 제한, 코덱 아티팩트, 패킷 손실, 저품질 마이크
  • 겹치는 발화는 주 화자를 보존하고 다른 화자는 억제하도록 학습됨
  • 웃음 보존이 중요하면 별도 모델 NVIDIA-NemotronLabs-RE-USE-laughter 사용

  • 판단: DNSMOS·UTMOS는 Sidon이 앞서고, 나머지 지표(NISQA·PESQ·STOI·화자 유사도·ASR 문자 정확도)는 RE-USE가 앞섬. 파라미터는 Sidon의 약 1/26, UniPASE의 약 1/52.
  • 샘플레이트별 부분 세트(16/44.1/48 kHz)에서도 비교 모델(UniSE, Resemble Enhance, ClearVoice) 대비 대부분 지표에서 앞선다고 모델카드에 표기됨.
  • 위 수치는 NVIDIA 모델카드의 자체 보고치. 독립 검증은 확인하지 못함.

사용법

# 모델 다운로드
huggingface-cli download nvidia/NVIDIA-NemotronLabs-RE-USE --local-dir ./NemotronLabs_REUSE --local-dir-use-symlinks False
cd ./NemotronLabs_REUSE

# noisy_audio/ 에 파일을 넣고 실행 → enhanced_audio/ 에 결과 저장
sh inference.sh

# 30초 초과 긴 음성 또는 GPU OOM → long_noisy_audio/ 에 넣고 실행 → Long_enhanced_audio/
sh inference_chunk.sh
  • 대역 확장(bandwidth extension)은 스크립트의 BWE 인자로 켜며, pip install resampy 필요
  • Mamba 환경은 SEMamba 사전 빌드 Docker 이미지 사용 가능
