본문 (Main Post)

RAG나 지식그래프로 에이전트 메모리 붙이던 방식, 이제 이 쪽도 있습니다.

Hindsight라는 오픈소스인데, 대화를 그대로 재생하는 대신 시간이 지날수록 스스로 학습하는 구조예요. LongMemEval 벤치마크에서 RAG와 지식그래프 방식보다 점수가 더 높다고 주장하고 있어요.

벌써 19,394 stars, 하루 +81씩 늘고 있어요. 핵심 4가지 뜯어볼게요.

댓글 스레드 (Reply Thread — 작성자 추가 내용)

1/ Retain·Recall·Reflect 3단 구조

저장할 때 LLM이 사실, 시간정보, 개체, 관계를 뽑아서 저장하는 Retain, 벡터 유사도·BM25 키워드·그래프·시간 필터링 4가지를 동시에 돌리는 Recall까지 있어요. 여기에 메모리를 다시 훑어보며 새 연결점을 만드는 Reflect 단계까지 거치니까, 예전에 놓친 맥락도 나중에 스스로 이어붙입니다.

2/ Docker 한 줄로 API+UI 동시 기동

docker run -p 8888:8888 -p 9999:9999 \
  -e HINDSIGHT_API_LLM_API_KEY=*** \
  ghcr.io/vectorize-io/hindsight:latest

이 한 줄이면 API는 8888번, 관리 UI는 9999번 포트에 뜹니다.

pip install hindsight-client

client.retain(bankid, content), client.recall(bankid, query) 두 메서드만으로 서버 세팅 없이 바로 연동해볼 수 있어요.

3/ 메모리를 3종류로 나눠 저장

종류설명
World facts세계 사실
Experiences경험
Mental Models사고모델

이렇게 3갈래로 나눠 저장하는 생체모방형 구조예요. LLM도 OpenAI, Anthropic, Gemini, Groq, Ollama, LMStudio, Minimax, Atlas Cloud까지 자유롭게 바꿔 끼울 수 있어서, 특정 벤더에 묶이지 않고 팀 사정에 맞춰 붙일 수 있습니다.

4/ 서버 없이 임베디드로도 동작

pip install hindsight-all

별도 서버 없이 라이브러리 형태로 바로 붙습니다. 성능 재현은 버지니아텍 Sanghani Center와 워싱턴포스트가 독립적으로 검증했다고 밝히고 있어요. Fortune 500 기업과 AI 스타트업 실서비스에도 이미 쓰이고 있어서, 벤치마크 숫자만으로 판단하기 애매했던 팀엔 참고할 근거가 하나 더 생기는 거예요.
