댓글 스레드 (Reply Thread / 다른 사용자)

  • Bonsai 27B 한계: 영어 외 언어 사용 시 실수가 잦음. 중국어 입력만 했는데도 중국어·영어·스페인어·아랍어를 섞어 답변. 별도 테스트에서는 541건 중 450건에서 곧바로 EOS 토큰만 출력.
  • 로컬 vs SOTA: SOTA 모델을 경험한 뒤에는 로컬 모델로 돌아가기 어렵다. tps·트러블슈팅·결과 품질을 고려하면 구독료를 내는 게 나을 수 있음.
    • 반론: SWE는 아니지만 데이터 추출, 요약, 웹 리서치, 이메일 검색 등 "흥미로운 작업"에는 로컬 모델을 적극 사용. 프라이버시 유지에도 좋음.
  • GTX 1060으로 Bonsai-27B 실행 성공 사례:
    • Bonsai-27B Q1_0가 6GB VRAM에서 CUDA, 4096 context, 99 GPU layers로 구동
    • 프롬프트 처리 111.48 tok/s, 생성 9.50 tok/s
    • 콜드 스타트 5/5, 단일 세션 요청 5/5 성공, OOM/CUDA 에러 없음
    • 증거: https://github.com/pitill0/legacy-gpu-llm/tree/main/results/maintainer/nvidia/pascal/gtx-1060-6gb/bonsai-27b-q10
  • 기타 질문/코멘트:
    • "양자화(quantization) 언급이 없다"
    • "Nemotron Ultra가 빠진 건 말이 안 된다" → "넣으면 됨"
    • "24GB VRAM + 768GB DDR4는 어느 등급?"
    • Ornith-1.0-9b 다음 테스트 대상으로 Bonsai-27b 관심
