Strata w/ Qwen3.8-Flash-Next
요즘 로컬 LLM 씬에서는 Strata가 대-유행이다.
그 중심에는 잘 설계된 추론 런타임과 Qwen3.8-Flash-Next 모델이 있다.
약 125B 규모의 Qwen3.8-FN은 일반적인 Dense 모델과 달리 일부 Expert만 활성화하는 구조로, Strata를 통해 제한된 VRAM과 시스템 RAM을 효율적으로 활용할 수 있다.
내 썩은 Tesla P40에서도 제법 쓸 만하게 돌아가는 걸 보면, 앞으로 이런 모델이 늘어날수록 DRAM의 중요성은 더욱 커질 듯하다.

Strata README 측정표의 답변 생성 속도 최고값은 94 tokens/s예요. HN 1면에 퍼진 제목은 'RTX 4090에서 100T/s'였고요.
Qwen3.8-Flash-Next(125B)를 12GB급 GPU에서 돌리는 리포예요. 측정표 값은 RTX 5070(12GB) 기준 Q20 94, IQ2XS 79, IQ3XXS 62 tokens/s 등이고, 각주에 Q20 행만 엔진 0.1.36(나머지는 0.1.26)이며 4K 답변·32K 프롬프트 조건이라고 적혀 있어요.
100이 나오는 문장은 'RTX 3090(24GB)이면 초당 약 100~140 토큰을 쓸 것(should)'이라는 추정이에요. 요건은 VRAM 12GB 이상·RAM 32GB 이상이고, UD-IQ4_XS 모델은 RAM이 약 80GB 미만이면 일부를 SSD에서 읽어 느려진다고 해요.
(참고: HN 1면 제목의 "100T/s"는 실측 최고값이 아니라 더 큰 카드에서의 추정치 — README 원문 수치와 혼동 주의)

프로젝트 상세 (GitHub README 보강)

Strata: Qwen3.8-Flash-Next(약 125B, MoE)를 일반 게이밍 PC에서 구동하는 오픈소스(MIT) 추론 엔진. Windows/Linux 원클릭 설치, OpenAI/Anthropic 호환 API 로컬 제공, 이미지 입력 옵션.

설치 / 연동

  • AI 코딩 에이전트(Claude Code/Cursor/Codex 등)에게 docs/AI_SETUP.md 따라 설치를 맡길 수 있음
  • 수동 설치: Windows START-HERE.bat, Linux ./setup.sh
  • 로컬 서버: http://127.0.0.1:8080 (OpenAI 호환 /v1, Anthropic 호환 /v1/messages, Codex용 /v1/responses`)
  • 벤치마크: BENCH.bat/./bench.sh (5-10분, 자체 PC 리포트 생성)
  • 멀티 GPU 지원 (2~3장 분산)

동작 원리

Qwen3.8-Flash-Next는 24,576개의 소규모 "Expert"로 구성된 MoE 모델이며 토큰당 10개만 활성화. GPU VRAM에는 가장 자주 쓰이는 Expert만 올리고, 전체는 시스템 RAM에, 룩업 테이블은 SSD에 배치하는 방식으로 12-24GB급 소비자 GPU에서도 125B 모델을 구동. Speculative decoding("Guess, then check")으로 1.6~1.8배 속도 향상.
