Claude Code — 문서가 알려주지 않는 설정 가능한 모든 것

원문: I Read the Claude Code Source Code So You Don't Have To (buildingbetter.tech)
GeekNews 토론: https://news.hada.io/topic?id=30030

개요

Claude Code 2.1.87에는 공식 문서에 없는 설정/기능이 많음. 개인(~/.claude/)과 프로젝트(.claude/) 단위로 설정을 분리해 Hooks, Skills, Agents를 세밀하게 제어 가능.

파일 위치

항목개인 설정프로젝트 설정
설정~/.claude/settings.json.claude/settings.json
Skills~/.claude/skills/<name>/SKILL.md.claude/skills/<name>/SKILL.md
Agents~/.claude/agents/<name>.md.claude/agents/<name>.md
Hooks~/.claude/hooks/—
⚠️ EXPERIMENTAL 필드는 Anthropic 엔지니어가 불안정하다고 표시한 것. 언제든 제거/이름 변경 가능.

문서에 없는 Hook 설정 필드 3가지

필드설명활용
once: true정확히 한 번만 실행 후 제거첫 세션 .env 템플릿 복사 등
async: true백그라운드 실행 (Claude 진행 차단 안 함)감사 로그 기록 (audit.jsonl)
asyncRewake: true기본은 async, exit code 2면 모델 재기동 → 차단민감 정보 스캔 후 차단

Skill Frontmatter 숨은 필드

필드설명
model실행 모델 오버라이드 (haiku/opus 등)
effort추론 깊이 (low/medium/high/max)

Agent Frontmatter 숨은 필드

필드설명
colorUI 색상 (red/orange/yellow/green/blue/purple/pink/gray)
memory지속 메모리 (user=전역, project=프로젝트별, local=비공개)

criticalSystemReminder_EXPERIMENTAL매 턴 시스템 리마인더 재주입 (⚠️ 불안정)
requiredMcpServers필요한 MCP 서버 정의 (없으면 Agent 로딩 안 됨)

Auto Mode + 자동 메모리 + Dream 통합

{
  "autoMemoryEnabled": true,   // 세션 후 백그라운드 메모리 추출
  "autoDreamEnabled": true     // 24h/5세션마다 메모리 통합
}
  • autoMemoryEnabled: 각 대화 후 세션의 장기 보관할 정보를 ~/.claude/projects/<path>/memory/에 기록
  • autoDreamEnabled: 누적 5세션 이상이면 중복 병합, 모순 해결, 날짜 변환, 오래된 항목 제거
  • 두 설정을 함께 켜면 세션→메모리→Dream→통합→다음 세션 학습 루프 형성

Magic Docs

정규식 /^#\sMAGIC\s+DOC:\s(.+)$/im 으로 감지.

# MAGIC DOC: API Endpoint Reference
_Only document public REST endpoints_
  • 업데이트 Agent가 백그라운드에서 해당 파일만 편집
  • 지시문 없으면 모든 내용 업데이트, 지시문 있으면 범위 제한
  • 헤더 삭제 시 추적 자동 중단

context: fork — 캐시 주의

Forked Skill은 부모의 prompt cache를 공유함. 다른 모델 지정 시 prefix가 달라져 cache miss 발생 → 비용 증가.

→ Forked Skill에서는 model 생략하거나 model: inherit 사용할 것.

의미와 한계

  • 이벤트 응답 Hook = AI 도구용 미들웨어 계층
  • 지속 메모리 + Dream = 모델 재학습 없는 경험 축적
  • Auto Mode 분류기 = 자연어 환경 설명 기반 안전 판단
  • 일부 댓글에서는 "이미 문서화된 내용"이라는 지적도 있으나 once/async/asyncRewake 등은 소스 코드 파서에서만 발견되는 비문서 필드
