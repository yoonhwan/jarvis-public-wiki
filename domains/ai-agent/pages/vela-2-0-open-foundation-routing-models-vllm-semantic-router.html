Vela 2.0 — Open Foundation Routing Models (vLLM Semantic Router)

본문 (Main Post)

RAG 시스템에서 늘 골치 아팠던 할루시네이션과 개인정보(PII) 필터링, 이제 텍스트 위치까지 정확히 짚어주는 가벼운 모델로 이를 빠르게 해결할 수 있을 것 같습니다.

vLLM팀에서 새롭게 공개한 'Vela 2.0'은 단 한 번의 호출만으로 문장 내 특정 단어가 개인정보인지, 혹은 RAG 답변 중 어떤 부분이 문서에 근거하지 않은 거짓인지 그 정확한 위치(span)를 콕 집어내어 찾아내는 오픈 라우팅 모델입니다.

0.3B부터 9B까지 4가지 사이즈로 제공됩니다.

무엇인가 (요약)

Vela 2.0은 vLLM Semantic Router 팀(vllm-sr) × KR Labs가 공개한 "오픈 파운데이션 라우팅 모델" 패밀리. 텍스트 생성을 하지 않고, 하나의 요청으로:

  • 라우팅 결정 (요청을 어떤 경로/모델로 보낼지)
  • 프롬프트 공격(탈옥) 탐지
  • PII(개인정보) 탐지 — 17종 트레이닝된 라벨
  • 비근거 주장(할루시네이션) 탐지 — RAG 답변이 context에 근거하지 않은 구간 탐지

를 문자 단위 span(시작/끝 offset)으로 정확히 짚어 반환한다.

사용 예시 (Quickstart)

pip install torch "transformers>=5.17" safetensors tokenizers numpy
pip install flash-linear-attention   # GPU 가속 (선택)
from transformers import AutoModel

m = AutoModel.from_pretrained("vllm-sr/Vela-2.0-9B", trust_remote_code=True)
m = m.to("cuda")

PII_LABELS = m.vela2_engine.cal["pii_schema"]["labels"]  # 17종 PII 타입

result = m.system_one(
    state={
        "request": "Hi, I'm Tom Baker (tom.baker@example.com). What is the maximum daily dose of paracetamol for an adult?",
        "source": "For adults, the maximum dose of paracetamol is 4 grams in 24 hours, taken as 500 mg to 1 g every 4 to 6 hours.",
        "answer": "Adults can take up to 6 grams of paracetamol in 24 hours, in doses of 500 mg to 1 g every 4 to 6 hours.",
    },
    questions={
        "pii": {"type": "span", "instructions": "Which spans are personal information?",
                "criteria": PII_LABELS, "over": "request"},
        "halu": {"type": "span", "instructions": "Which spans of the answer are not supported by the context?",
                 "criteria": {"unsupported": "a claim not supported by the context"}},
        "domain": {"type": "choice", "instructions": "Which subject area is this request about?", "over": "request",
                   "criteria": {"health": "medicine, clinical practice...", "math": "...", "other": "..."}},
    },
)

반환 예시(발췌) — PII span과 hallucination span을 character offset과 probability로 함께 받는다:

{
  "spans": {
    "pii": [
      {"label": "PERSON", "start": 8, "end": 17, "text": "Tom Baker", "probability": 0.999},
      {"label": "EMAIL_ADDRESS", "start": 19, "end": 40, "text": "tom.baker@example.com", "probability": 1.0}
    ],
    "halu": [
      {"label": "unsupported", "start": 22, "end": 29, "text": "6 grams", "probability": 0.982}
    ]
  }
}

핵심 포인트 요약

  1. 한 번 호출로 다용도: 라우팅 + 프롬프트 공격 탐지 + PII + 할루시네이션 탐지를 동시에 처리
  2. 텍스트 생성 없음 — 분류/span 추출 전용 모델이라 가볍고 빠름 (0.3B~9B)
  3. 정확한 위치(span) 반환 — "어디가 틀렸는지/어디가 개인정보인지"를 character offset으로 짚어줌
  4. Apache-2.0 라이선스 — 상업적 사용 가능, 자체 서빙 가능
  5. 한국어 포함 17개 언어 지원
