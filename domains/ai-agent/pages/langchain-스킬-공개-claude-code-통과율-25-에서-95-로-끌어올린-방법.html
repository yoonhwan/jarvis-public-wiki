📌 핵심 요약

LangChain이 AI 코딩 에이전트를 위한 첫 번째 스킬 세트를 공개했다.

LangChain / LangGraph / LangSmith 생태계 특화 스킬을 장착하면:

태스크스킬 없음스킬 있음
LangChain 태스크25%95%
LangSmith 태스크17%92%

🧠 스킬(Skill)이란?

코딩 에이전트의 성능을 높이기 위한 지침 + 스크립트의 묶음

핵심 설계 원칙: Progressive Disclosure (점진적 공개)

  • 에이전트가 필요한 순간에만 해당 스킬을 불러온다
  • 처음부터 모든 정보를 컨텍스트에 넣으면 오히려 성능 하락
  • 마크다운 파일 + 스크립트 구성 → 어떤 코딩 에이전트에도 이식 가능

🔄 에이전트가 에이전트를 개선하는 루프

LangSmith 스킬의 핵심 가치: 자기 개선 사이클

코딩 에이전트
  → 실행 트레이스를 LangSmith로 전송
  → 트레이스 분석 + 문제점 요약
  → 테스트 데이터셋 + 평가자 자동 생성
  → 에이전트 아키텍처 개선
  → 반복
"에이전트 개선 루프는 점점 터미널 기반의 다른 에이전트에 의해 주도될 것"

📊 스킬 평가 방법론

→ 상세 가이드: [[03-evaluating-skills]]

LangChain이 공개한 스킬 평가 4단계:

  1. 클린 테스트 환경 구성 (Docker 등 일관된 sandbox)
  2. 태스크 정의 (제약된 태스크 + 명확한 메트릭)
  3. 스킬 정의 (AGENTS.md/CLAUDE.md 활용, 12개 이하 유지)
  4. 성능 비교 (스킬 있음/없음 A/B 테스트)

핵심 발견:

  • 스킬 포함 시 태스크 완료율 82%, 스킬 없으면 9%
  • 스킬이 항상 올바르게 호출되지 않음 → AGENTS.md에 "언제 어떤 스킬" 안내 필수
  • 유사 스킬 20개 → 오호출 발생, 12개로 줄이자 정확도↑
