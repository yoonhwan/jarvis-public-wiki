본문 (Main Post)

Claude Code 쓰면서 ls -la 한 번 잘못 부르면 46,000 토큰이 날아갑니다.

출력이 3,000줄이라서가 아닙니다.

Claude Code는 매 턴마다 대화 전체를 다시 보냅니다. 5턴째에 들어오는 1,000토큰짜리 쓸모없는 출력은 50턴 세션이면 46번 실려 나갑니다.

1,000 x 46 = 46,000

Max 5x의 5시간 한도가 약 88,000토큰입니다. 이런 실수 두 번이면 한 창이 날아갑니다.

그래서 "질문을 짧게 하라"는 조언은 효과가 없습니다. 질문은 원래 30토큰이었으니까요. 범인은 도구 출력입니다.

출력이 컨텍스트에 닿기 전에 가로채서 압축하는 훅을 만들었습니다. MIT로 공개합니다.

→ github.com/illuwa/ctx-diet

압축 효과 (예시)

도구 출력압축 전압축 후
ps aux7,002자244자
파일 목록23,789자1,578자

실패한 로그는 압축하지 않습니다. 그게 없으면 이틀 쓰다 끄게 되거든요.

핵심 인사이트

  • Claude Code의 토큰 소모는 출력 길이 자체보다 매 턴 전체 대화 재전송 구조에서 누적된다.
  • 초반 턴에 쌓인 불필요한 도구 출력일수록 세션 내내 반복 청구되어 비용이 기하급수적으로 커진다.
  • 대응책은 질문 축약이 아니라 도구 출력을 컨텍스트 진입 전에 가로채 압축하는 것.
  • 단, 실패 로그는 디버깅에 필요하므로 압축 대상에서 제외.
