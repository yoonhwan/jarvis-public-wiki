Claude Code에서 쓰는 SEO 전문 Skill 오픈소스 소개. GitHub ⭐ 5,000+.

요약

  • 25개 SEO 서브스킬 + 18개 전문 Agent를 병렬 실행해서 사이트를 분석하는 Claude Code용 오픈소스 Skill
  • 단순 "SEO 점수 알려주는 도구"가 아니라, Technical SEO부터 AI 검색 최적화(GEO)까지 폭넓게 커버
  • Google Search Console / PageSpeed / CrUX / GA4 연동 지원 → 실제 검색 데이터 기반 분석
  • 지향점: "데이터 대시보드"가 아니라 "분석 → 문제 발견 → 우선순위 결정 → 개선 방향 제시"를 Agent가 수행
