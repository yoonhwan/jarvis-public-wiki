한국 변호사를 위한 Claude Code 통합 패키지

한 줄 요약: 한국 변호사를 대상으로, 사건 폴더를 통째로 읽고 준비서면 초안 작성까지 돕는 Claude Code 통합 패키지.

개요

법률 실무 도메인에 맞춘 Claude Code 플러그인/설치형 패키지. 사건 폴더 전체를 읽어들여 준비서면 초안까지 작성하는 환경을 한 줄 명령으로 설치한다.

  • GitHub: jurisupport/jurisupport-plugins
  • 대상: 한국 변호사
  • 핵심 기능: 사건 폴더 Ingest → 준비서면 초안 작성

자비스 관점

  • 법률 실무 도메인에 맞춘 Agent/CLI 패키징 사례
  • "사건 폴더 전체 ingest → 준비서면 초안" 흐름은 도메인별 Agent/CLI 패키징 레퍼런스
  • 추가 검토 시 GitHub 저장소의 설치 방식, 데이터 보안/비밀정보 처리, 변호사 업무 산출물 검증 장치 확인 필요
