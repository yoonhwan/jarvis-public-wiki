Coqui STT — 오픈소스 음성 인식(STT) 툴킷

자체 데이터로 음성 인식 모델을 만들고 배포하고 싶다면? 🎤

본문 (Main Post)

Coqui STT는 Mozilla DeepSpeech를 계승한 오픈소스 STT 툴킷입니다.

  • 사전학습 모델로 바로 전사(transcribe) 가능
  • 자체 데이터로 파인튜닝하거나 새 언어를 처음부터 학습하는 것도 가능
  • Python · Java · JavaScript 등 다양한 언어로 통합 가능
  • 라즈베리파이처럼 저전력 기기에서도 실행 — 가장 큰 매력
  • 오프라인 추론에 적합해 프라이버시 보호가 필요한 프로젝트에 적합
