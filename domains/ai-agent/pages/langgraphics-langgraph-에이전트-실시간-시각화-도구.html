LangGraphics: LangGraph 에이전트 실시간 시각화 도구

📋 요약

LangGraph 에이전트의 실행 과정을 브라우저에서 실시간으로 시각화해주는 오픈소스 도구. 컴파일된 그래프를 watch()로 감싸기만 하면 설정 끝.

핵심 포인트

  • 실시간 시각화: 분기(Branches), 루프(Loops), 실패 지점을 눈으로 직접 확인
  • Zero Config: 복잡한 설정 없이 watch() 한 줄로 적용
  • Local Only: 데이터가 외부로 나가지 않아 보안 걱정 없음
  • 디버깅 효율: 터미널 로그 대신 시각적 확인으로 디버깅 시간 단축

사용법

from langgraphics import watch

# 컴파일된 그래프를 watch()로 감싸기만 하면 끝
watch(compiled_graph)

브라우저에서 에이전트 실행 과정을 실시간으로 확인 가능.
