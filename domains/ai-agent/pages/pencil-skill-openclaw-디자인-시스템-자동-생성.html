Pencil Skill — OpenClaw 디자인 시스템 자동 생성

Pencil이 MCP를 공식 지원하는데, 데스크탑 앱을 켜놔야 동작합니다. OpenClaw에서 활용하기엔 부족해서, 앱 없이 .pen 파일을 직접 생성/편집하는 Agent Skill을 만들었습니다.

핵심 내용

문제

  • Pencil MCP는 데스크탑 앱이 실행 중이어야 동작
  • OpenClaw 같은 headless 환경에서는 활용 불가

해결: pencil-skill

  • .pen 파일은 JSON 기반 → Node.js built-in만으로 읽기/쓰기/검증
  • CLI 스크립트 8개 제작
  • 디자인 룰 41개 강제 적용:
    • AI 단골 파란 버튼 차단
    • 4pt/8pt 그리드 강제
    • 컬러 하드코딩 금지
    • Light/Dark 동시 생성 필수
Pencil 공식이 headless CLI를 "coming soon"이라고 해놨는데, 기다리기 싫어서 먼저 만든 거예요.

설치 & 사용

npx skills add de-novo/pencil-skill
  • Claude Code, Cursor, Codex, Gemini CLI 전부 지원
  • OpenClaw에서는 완전 무인 자동화

📚 Pencil 공식 문서 요약 (docs.pencil.dev)

Pencil이란?

  • IDE(VS Code, Cursor) 내장 벡터 디자인 툴 + 독립 데스크탑 앱
  • .pen 파일 = JSON 기반, Git 버전 관리 가능 (코드와 동일 커밋/브랜치/머지)
  • 설계 철학: 디자인과 코드를 같은 환경에 — Figma처럼 별도 앱 전환 불필요

핵심 기능: Design ↔ Code 양방향 싱크

방향동작
Design → Code.pen 디자인 → React/Next.js/TypeScript 컴포넌트 자동 생성
Code → Design기존 코드 컴포넌트 → Pencil 캔버스로 역가져오기
Two-Way Sync디자인 수정 → 코드 반영, 코드 수정 → 디자인 반영 반복

MCP 서버 통합

  • Pencil 실행 시 MCP 서버 자동 기동 (로컬, 클라우드 의존 없음)
  • AI 에이전트(Claude Code, Codex CLI)가 .pen 파일 읽기/수정 가능
  • Cursor Settings → Tools & MCP에서 Pencil 서버 확인 가능

Design Token & CSS Variable 싱크

  • globals.css의 CSS 변수 ↔ Pencil 변수 양방향 동기화
  • Figma 토큰 복사 → Pencil 변수로 변환 가능
  • 이미지는 Figma→Pencil 복사 안 됨 (SVG 또는 재임포트 필요)

설치 옵션

  • VS Code/Cursor 확장: 마켓플레이스에서 "Pencil" 검색
  • 데스크탑 앱: macOS(.dmg), Linux(.deb/.AppImage), Windows
  • AI 기능 필수: Claude Code CLI 인증 필요
  • ⚠️ Auto-save 미지원 — 자주 저장 필요

🔥 사용 사례 & 인사이트 (웹 리서치)

실제 사용 사례

1. UI/UX 래피드 프로토타이핑

  • 무한 캔버스에서 AI 프롬프트로 화면/컴포넌트 즉시 생성
  • "Create a login form" → 디자인 + 코드 동시 산출

2. Figma → 프로덕션 코드 원스텝 변환

  • Figma 요소 복사 → Pencil에 붙여넣기 → 벡터/텍스트/스타일/레이아웃 보존
  • AI가 매칭 React/HTML/CSS 컴포넌트 즉시 생성

3. 멀티 에이전트 병렬 작업 (AI Multiplayer)

  • 에이전트 1: Pencil AI가 디자인 정제
  • 에이전트 2: 외부 에이전트(MCP 경유)가 코드 생성
  • .pen 파일 Git 커밋 → 브랜치/머지로 팀 협업

4. 기존 코드베이스 비주얼라이제이션

  • src/components/Button.tsx → Pencil 캔버스에 비주얼 재현
  • 디자인 개선 → 코드에 다시 반영 → 반복 이터레이션

🐝 Pencil Swarm 모드 (AI Multiplayer)

"AI singleplayer is the new multiplayer"

핵심 개념

  • 최대 6개 AI 에이전트가 하나의 캔버스에서 동시 병렬 작업
  • 각 에이전트가 캔버스의 다른 영역을 담당 — 순차 대기 없음
  • 실시간 화살표로 어떤 에이전트가 어디를 수정 중인지 시각 피드백

동작 예시

에이전트 1 → "히어로 섹션 강화"
에이전트 2 → "추천사 섹션 추가"
에이전트 3 → "푸터 리파인"
에이전트 4 → "가격 페이지 생성"
→ 4개가 동시에 캔버스에 그려짐!

워크플로우

  1. Pencil 캔버스에서 여러 프롬프트 동시 입력
  2. 에이전트들이 각자 담당 영역에서 병렬 생성
  3. 캔버스에서 실시간 시각 피드백
  4. 결과 확인 → 마음에 안 드는 부분만 추가 프롬프트
  5. 확정 → 코드 export (React/HTML/CSS)

Gas Town 연결점

  • Pencil Swarm: 6개 AI 에이전트 → 디자인 캔버스에서 병렬 작업
