로컬 AI 음성 워크플로우와 TTS/STT/목소리 클로닝

한 줄 요약: ElevenLabs 같은 구독형 음성 서비스를 대체할 수 있는 로컬 AI 기반 TTS/STT/목소리 클로닝 워크플로우와 추천 모델 조합.

워크플로우 구성

단계역할추천 모델
목소리 클로닝음성 복제/합성VoxCPM2 (자연스러움 우수)
보이스 체인지음성 변환Seed-VC
번역/대본 생성언어별 스크립트translategemma
STT (음성→텍스트)음성 인식로컬 모델
TTS (텍스트→음성)음성 합성로컬 모델

주요 포인트

  • 모든 모델이 맥북 로컬 환경에서 실행 가능 → 비용 걱정 없이 무제한 생성
  • 유튜브 주소로 바로 샘플링 가능한 워크플로우 확장
  • 각 역할별로 보이스를 지정하면 'AI 팟캐스트' 제작 가능
  • SaaS 음성 서비스(ElevenLabs 등)의 비용 구조 대비 로컬 모델 기반 무제한 생성의 경쟁력

자비스 관점

  • 로컬 음성 파이프라인의 핵심 구성 요소: VoxCPM2(voice cloning), Seed-VC(voice conversion), translategemma(translation/script generation)
  • 실제 도입 전 각 모델의 라이선스, 상업적 이용 가능 여부, Apple Silicon/Mac 로컬 성능 별도 확인 필요
