오라클 클라우드 서버 무료로 얻기 성공기

한 줄 요약: Oracle Cloud Always Free에서 OCI CLI와 Codex를 활용해 A1 Flex 인스턴스를 생성·증설하여 최종적으로 4 OCPU / 24GB RAM 서버를 확보한 경험담.

워크플로우

사전 준비

  1. Oracle Cloud 계정 가입
  2. 무료 티어 → 유료 계정 전환 (카드 등록만, 비용 없음)
  3. OCI CLI 설치 및 설정
  4. 사용자 OCID, 테넌시 OCID, 리전 설정
  5. VCN/subnet 기본 네트워크 구성

Codex 자동화 흐름

  1. Codex에게 "OCI CLI로 무료 티어 한계까지 설정" 지시
  2. 전략: 4 OCPU / 24GB → 실패 시 2 OCPU / 12GB로 낮춰 재시도
  3. 예약 작업으로 천천히 재시도 + 성공 시 Telegram 알림
  4. 성공 후 동일 인스턴스를 4 OCPU / 24GB로 증설

핵심 포인트

  • "Out of host capacity" 에러는 설정 오류가 아니라 리전 용량 부족 → 스펙을 낮춰 생성 후 증설
  • "요청 수락"과 "실제 스펙 반영"을 구분해 상태 재확인 필수
  • 콘솔 수동 클릭이 아닌 OCI CLI를 통해 Codex/에이전트가 리소스 생성·확인·재시도 자동화

최종 결과

  • VM.Standard.A1.Flex, 4 OCPU / 24GB RAM
  • Ubuntu 22.04 ARM
  • 춘천 리전
  • Always Free (평생 무료)

자비스 관점

  • OCI CLI를 준비해 Codex/에이전트가 인프라 생성·확인·재시도를 수행한 자동화 사례
  • AI 에이전트가 클라우드 리소스를 관리하는 워크플로우 참고 자료
